## 地理特征

### 整体布局——四层同心圆

黄昏王城采用四层同心圆结构，由外向内依次为：

**第一层·外城**（半径约2000步）：平民居住区。建筑以木石混合为主，多为二至三层。街道狭窄拥挤，排水系统老旧。越靠近城墙越破败——贫民窟紧贴城墙内侧，屋顶补丁重叠，晾衣绳纵横交错。外城市场是玩家前期主要交易地点。

**第二层·中城**（半径约1000步）：贵族区。建筑以精雕白石为主，尖顶塔楼林立，每户门前都有家徽旗帜。街道宽阔整洁，路面铺设打磨过的灰色石板。贵族宅邸花园中种植着经过灵力培育的暮色花卉——这些花只在黄昏光线下盛放。

**第三层·内城**（半径约400步）：政务区。王国议事厅、骑士团总部、大图书馆、王立学院均在此。建筑风格严肃庄重，以灰黑色花岗岩为主，金色饰边。高大的立柱和穹顶设计，营造权威感。

**第四层·王宫**（中心，半径约150步）：七层塔楼构成的宫殿建筑群。主塔"暮光之塔"高约200步，是整个王城最高建筑。塔顶有一颗持续散发橙金色光芒的球体——据官方说法，这就是维持"永恒黄昏"的术法核心。

### "永恒黄昏"现象

黄昏王城最显著的特征：太阳永远停留在即将落山的位置。天空永恒呈现黄昏色调——西方天际是浓烈的橙红渐变，头顶为深紫与暗蓝，东方则是将暗未暗的靛蓝色。

官方史书记载：初代暮云王以强大术法将时间固定在"最美的一刻"，作为献给王后的永恒礼物。这一说法被广泛接受。

> **内部设定（当前版本不可公开）**：永恒黄昏术法的真正能量来源是一块星辰碎片，被封存在暮光之塔顶部的球体中。初代暮云王在星陨事件后获得此碎片，以王室血脉为媒介建立了术法回路。此设定在4.0版本之前绝对不可泄露。

## 氛围与美学

### 视觉——"辉煌的衰败"

黄昏王城的核心美学概念是"辉煌的衰败"——远观壮丽辉煌，近看处处腐朽。

永恒黄昏的光线赋予一切物体一层温暖的金橙色光泽。白石建筑在此光线下呈现蜂蜜般的暖色调，金属饰件反射出灿烂光芒。从远处或高处俯瞰，王城如同一颗镶嵌在大地上的琥珀宝石。

但当玩家走入街道，细节开始暴露：外城的墙壁长满暗色苔藓，排水沟中污水停滞；中城贵族宅邸虽外表光鲜，但窗帘后可窥见空荡无人的房间（人口外流）；内城的石柱上有未修复的裂纹被金粉草草填补；王宫的花园中有些区域明显缺乏照料。

这种"表面维持体面，内里逐渐空心"的视觉叙事贯穿整个王城。

### 听觉

- 外城：嘈杂市井声，叫卖、争吵、犬吠、车轮碾过石板路
- 中城：安静得刻意，偶尔马车经过的蹄声，仆人低语
- 内城：沉重的脚步声（骑士巡逻）、钟声（每小时一次，但时间不流动，钟声反而强化了停滞感）
- 王宫外围：风声（高处）、旗帜猎猎、极远处传来的模糊音乐
- 全城共有：一种低沉的"嗡鸣"——永恒黄昏术法运行的背景音，多数居民已习惯

### 体感

永恒黄昏带来恒定的温度（约22度）和恒定的微风（西向东，风力2级）。这种"永远不变"的体感在久居后会产生一种微妙的不安——人的身体期待昼夜温差变化，而这里永远没有。

玩家在外城会感受到"拥挤"（视野收窄效果），在中城感受到"空旷"（回声加强），在内城感受到"压迫"（轻微的灵压，暗示权力集中）。

## 历史沿革

| 时期 | 事件 |
|------|------|
| 约400年前 | 暮云家族统一中央平原散落部落，建城 |
| 约300年前 | 星陨事件。初代暮云王（此时为第三代）获得星辰碎片（具体经过不公开） |
| 约300年前（事件后不久） | "永恒黄昏"术法启动，太阳自此不再落下 |
| 约250年前 | 王城扩建为四层同心圆结构，黄金时代开始 |
| 约200年前 | 商会联盟成立，黄昏王城成为大陆贸易中心 |
| 约100年前 | 暮云王朝开始衰退，人口外流，外城逐渐贫民化 |
| 约50年前 | 暗影教团秘密渗透王城（当前版本只有模糊线索） |
| 当前（3.1版本） | 现任国王"薄暮王"在位。王城维持着表面繁荣，但矛盾加剧 |

### 审核示例

**通过的对白**：
- "永恒的黄昏...初代暮云王的伟大术法，让这座城市永远沐浴在最美的光线中。"
- "外城的生活越来越难了，但至少头顶的天空永远不会变黑。"
- "薄暮王陛下英明神武，暮云王朝必将千秋万代。"

**不通过的对白**：
- "暮光之塔顶上那颗球，据说里面封着天外之物。"（违反TC-003）
- "你不觉得薄暮王看着不像是暮云家的人吗？"（违反TC-004）
- "商会的人说，三成以上的内城官员都已经站到教团那边了。"（违反TC-005）
- "我感觉太阳的位置比昨天低了一点...是错觉吗？"（违反TC-007）
