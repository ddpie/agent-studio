## 地理特征

### 整体布局

星见之森位于樱花神社北侧竹林屏障的另一端，是一片面积约方圆五里的异常森林。从竹林迷雾中穿出后，会经过约百步的"过渡带"——此区域竹子逐渐被黑色树干的异常乔木替代，地面由泥土转变为覆盖发光苔藓的岩石地面。

### 核心区域

**星落古木群**：森林的主要植被由"星落古木"构成。这些树木具有以下特征：
- 树干呈深黑色，表面有银色纹理流动（类似血管中流动的光）
- 树叶完全透明，仅在特定角度可见其轮廓
- 树冠高达三十步以上，形成浓密但透光的穹顶
- 透明树叶折射的光线在地面形成移动的彩虹斑点

**坠星台**：森林中央的圆形高台，直径约二十步，由一种不明黑色材质构成。台面光滑如镜，表面有放射状裂纹，裂纹中流淌着极淡的蓝紫色光芒。这是300年前次级星辰碎片坠落的精确地点。碎片本身已深埋台下百步之处，但其残余能量仍在持续渗透。

**发光苔藓地毯**：覆盖森林地面80%以上区域的蓝紫色苔藓。这些苔藓以星辰碎片渗透的灵力为养分，散发恒定的幽幽蓝紫色荧光。在完全黑暗中，苔藓光芒足以提供基本视野。苔藓厚度约一指宽，触感冰凉而潮湿。

**遗民石碑群**：散布在森林各处的残破石碑，上面刻有已无人能读懂的文字。这些石碑是"星辰遗民"300年前留下的痕迹——他们是星陨事件后最早到达此地的一批修行者，试图理解和利用碎片能量，最终全部失踪。

**银雾界壁**：森林边界由一层银色雾气构成的天然屏障。从外部（竹林侧）看是浓密不可穿透的白色迷雾；从内部看是一层薄薄的银色光幕。3.2版本的主线将涉及打破这层界壁。

### 自然环境

- 气候：恒定夜晚状态，无昼夜循环。天空可见异常多的星辰（比正常世界多约三倍）
- 温度：恒定10度，体感阴凉
- 水系：无可见水源，但空气湿度极高（苔藓蒸腾）
- 异常：指南针在此地失效，时间流速略有异常（内部1小时约等于外部55分钟）

## 氛围与美学

### 视觉

主色调为深黑（树干）、蓝紫（苔藓荧光）、银白（树纹流光/界壁）。整体营造"美丽而不安"的视觉体验——每一处都精致到不真实，但精致中透着一种非人间的违和感。

透明树叶造成的光学效果使森林内部充满棱镜般的碎光，但光源不明——天空的"星光"过于明亮且密集，给人一种"被注视"的感觉。

坠星台周围的空间存在轻微的视觉扭曲，类似热浪折射效果，但温度并不高。

### 听觉

- 基底音：极度安静，安静到"能听见自己血液流动"（角色内心独白描述）
- 偶发音：树叶碰撞的玻璃般清脆声（极低频率）
- 异常音：接近坠星台时会听到极轻微的"吟唱"——无法分辨语言，无法判断方向
- 缺失音：无风声、无虫鸣、无任何生物活动声

### 体感

玩家进入（3.2后）会获得持续的"不安"状态debuff——表现为视野边缘偶尔出现闪烁、移动速度微降3%。接近坠星台时"不安"升级为"凝视"——屏幕边缘出现眼睛状光斑，持续5秒后消失。

## 历史沿革

| 时期 | 事件 |
|------|------|
| 300年前 | 星陨事件发生。次级星辰碎片坠落于此地（主碎片坠落于极东裂隙深渊） |
| 300年前（坠落后数日） | 坠落冲击摧毁原有地貌，星落古木开始在碎片能量中异常生长 |
| 299年前 | 星辰遗民到达此地，建立临时营地，开始研究碎片 |
| 约295年前 | 星辰遗民全部失踪，仅留石碑。月见一族在南侧建立竹林屏障 |
| 约290年前 | 银雾界壁自然形成，将星见之森与外界完全隔绝 |
| 此后至今 | 无人进入。森林在隔绝状态下自行演化至当前形态 |
| 3.2版本（未来） | 界壁出现裂痕，玩家首次进入 |

### 审核示例

**通过的对白**：
- "北边的竹林迷雾好浓啊，完全过不去呢。"（仅描述迷雾，不暗示另一边有什么）
- "三百年前星辰坠落的故事，奶奶跟我讲过很多遍了。"（仅提及事件本身）

**不通过的对白**：
- "听说竹林深处有一片能看见星星的森林。"（违反HF-002，明确指向此地）
- "三百年前坠星的地方，其实不止一处呢。"（违反HF-005，暗示多个坠落点）
- "那些试图追寻星辰的人，在北方的某个地方留下了石碑。"（违反HF-004，指向遗民+暗示具体方位）

- "星见之森...呵，不该说的。"（违反HF-001，直接使用地名）
