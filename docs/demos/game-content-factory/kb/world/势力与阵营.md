# 势力与阵营

## 概述

夜见世界的政治格局由五大公开势力主导，另有隐秘组织在暗中活动。各势力之间的关系复杂多变，既有历史积怨也有现实利益纠葛。玩家所属的"夜狩众"定位为中立第三方，可与各势力建立不同程度的关系，但始终保持独立。

---

## 五大势力

### 一、星读院（せいどくいん）

**标志**：七芒星（六角代表前六星，中心空缺代表"被封印的第七"）
**信仰**：星神——七曜星辰的拟人化信仰体系
**信条**：「观星知命，以光御暗」
**总部**：星见塔（花明原最高点）
**领导者**：院长 天城清明（あまぎ きよあき）

#### 领导者档案

- **种族**：人类
- **年龄**：60岁
- **实力等级**：第五阶（星主）
- **特征**：外表儒雅温和的老者，但决策冷酷果断。精通术式道中的"星读术"——通过观测星辰运行轨迹预测未来趋势（非精确预言，更接近概率推演）。
- **公开立场**：以维护世界秩序为己任，主张集中资源对抗暗星威胁
- **隐含问题**：其决策是否真的出于公心？3.1揭示的"第七研究所"说明星读院在进行未向公众披露的秘密研究

#### 组织结构

星读院采用学术等级制，从低到高为：星生 → 星士 → 星官 → 星卿 → 院长。权力集中于上层五名星卿与院长组成的"六星会议"。下设七个研究所，其中第一至第六研究所分别对应六种正属性星力的研究，第七研究所的存在直到3.1版本才被揭示。

#### 势力特色

- 掌握最完整的星力理论体系与术式库
- 拥有跨种族的学术权威（各种族中均有星读院培养的学者）
- 维护着大陆范围的"星力监测网"，可以探测异常星力波动
- 近年来权力扩张明显：以"暗星应急法令"为名限制了大量自由

#### 版本关键事件

| 版本 | 事件 |
|------|------|
| 1.0 | 星读院作为玩家初期指导方登场 |
| 2.1 | 星读院强推"星力管制令"，与夜之王庭冲突 |
| 3.1 | 第七研究所存在被揭露，内容仍是秘密 |

### 二、夜之王庭（やのおうてい）

**标志**：弯角环血月（鬼角环绕血色满月）
**信仰**：无统一信仰，崇尚力量本身
**信条**：「力量即正义，弱者无需言语」
**总部**：赤月城（常夜岭鬼哭山腹地）
**领导者**：鬼王 岩场暁（いわば あかつき）

#### 领导者档案

- **种族**：鬼族
- **年龄**：450岁
- **实力等级**：第五阶（星主），鬼族特有状态"永觉"
- **特征**：身高超过两米的壮硕鬼族，双角呈深红色。"永觉"是鬼族中极罕见的状态——鬼力觉醒到达极致后，肉体本身成为星力容器，不再衰老。性格直率暴烈但并非愚蠢，对同族有强烈保护欲。
- **公开立场**：鬼族利益至上，拒绝星读院的越权干涉
- **隐含问题**：永觉状态是否有未知代价？暴烈性格下是否有对同族未来的深远思考？

#### 组织结构

夜之王庭采用武力世袭制——鬼王由前任指定或武力夺取。王庭下设"四将"，分别统领军事、内政、外务、刑罚。四将必须是通过"鬼力觉醒"达到第三阶以上的鬼族。鬼族社会中，实力是唯一的晋升通道，无论出身。

#### 势力特色

- 个体战斗力在五大势力中最强
- 军事组织严密，全民皆兵传统
- 对阴属性有天然抵抗力（鬼力觉醒过程本身就是对内部阴属性的掌控）
- 主张对夜堕者"先斩后奏"，不区分觉醒与否

#### 版本关键事件

| 版本 | 事件 |
|------|------|
| 1.0 | 常夜岭开放，玩家首次接触鬼族文化 |
| 1.1 | 晨关冲突事件，人鬼边境紧张 |
| 2.1 | 反对星力管制令，鬼王公开威胁开战 |

### 三、幻月社（げんげつしゃ）

**标志**：铜镜映新月九狐尾（铜镜中映出新月，镜缘装饰九条狐尾纹样）
**信仰**：万象皆幻——认为物质世界是心识的投射
**信条**：「万象皆幻，唯心为真」
**总部**：月映宫（霜月谷中心）
**领导者**：社长 白夜（びゃくや）

#### 领导者档案

- **种族**：狐族（九尾）
- **年龄**：2000岁以上（确切年龄不详）
- **实力等级**：推测第五阶以上（从未全力出手过，真实实力未知）
- **特征**：外貌呈现为二十余岁的女性形态，银白色长发，九条尾巴通常以幻术隐藏。言行举止间有种超然物外的从容感，仿佛一切都在意料之中。极少离开霜月谷。
- **公开立场**：不干涉外界事务，维护狐族独立与安宁
- **隐含问题**：活了两千年的存在真的对外界无动于衷？其"不干涉"是否本身就是一种干涉？

#### 组织结构

幻月社并非严格的政治组织，更接近学术/文化共同体。社长之下设"七镜"——七名掌管不同领域的高阶狐族（幻术研究、历史记录、对外交涉、内部治安、幼族教育、幻域研究、禁术监管）。决策以合议制为主，但白夜拥有最终否决权。

#### 势力特色

- 情报能力最强（幻术可用于侦查与渗透）
- 防御性极强（整个霜月谷被大型幻术保护，几乎不可能被正面攻破）
- 对"认知"与"真实"的研究深度远超其他势力
- 最封闭的势力，与外界互动最少

#### 版本关键事件

| 版本 | 事件 |
|------|------|
| 2.4 | 霜月谷开放，幻月社正式登场 |
| 3.0 | 白夜罕见地派遣使者参加五族会议 |

### 四、潮音阁（ちょうおんかく）

**标志**：螺旋海螺（象征声波的无限延伸）
**信仰**：潮之声——认为世界的本质是振动/频率
**信条**：「万物皆有声，聆听即是理解」
**总部**：响岛声殿（潮音海中心岛屿）
**领导者**：阁主 渡凪（わたなぎ）

#### 领导者档案

- **种族**：海民
- **年龄**：160岁
- **实力等级**：第四阶（星驭）
- **特征**：身材修长的中年男性，皮肤呈现淡蓝色调，双耳后有鳃状纹路。性格沉稳内敛，说话语速极慢——海民相信急促的言语会扰乱灵脉共振。是公认的"聆听"能力最强者，据传可以听到整个潮音海域范围内的灵脉振动。
- **公开立场**：和平主义，主张通过对话解决争端
- **隐含问题**：他听到的灵脉之声中，是否包含了某些不该听到的信息？

#### 组织结构

潮音阁采用松散联邦制，各岛自治，阁主更多是精神领袖与学术权威。重大决策通过"潮会"——各岛代表以特殊声波通讯进行远程合议。潮音阁下设"五音堂"，分别负责：战斗应用、医疗恢复、通讯传递、环境探测、灵脉研究。

#### 势力特色

- 通讯与侦测能力卓越（声波远距离传输）
- 医疗技术最先进（声波共振可用于治疗）
- 海上战斗能力强大，但陆战较弱
- 最温和的势力，通常充当调停角色

#### 版本关键事件

| 版本 | 事件 |
|------|------|
| 1.4 | 潮音海开放，潮音阁登场 |
| 2.2 | 沉默区异常扩张事件 |
| 3.0 | 渡凪提出"灵脉之声异变"警告 |

### 五、夜狩众（やがりしゅう）——玩家归属势力

**标志**：刀刃映星（直刀刀身上映出星光的图案）
**信仰**：无统一信仰
**信条**：「不为势力效忠，只斩黑暗」
**总部**：夜行馆（花明原与常夜岭交界地带）
**领导者**：馆主 一条灰二（いちじょう はいじ）

#### 领导者档案

- **种族**：人类
- **年龄**：53岁
- **实力等级**：第四阶（星驭）
- **特征**：寡言的中年男性，左臂为星力义肢（原臂在一次夜堕者讨伐中失去）。不苟言笑但对新人（玩家）有隐含的关怀。战斗风格极为实用——不追求华丽，只求一击必杀。
- **公开立场**：保持绝对中立，只对"黑暗"（夜堕者、阴属性异变体）动手
- **核心原则**：不杀觉醒夜堕者（保持自我意识的个体不是"黑暗"）

#### 组织结构

夜狩众规模远小于其他四大势力，采用扁平化的小队制。馆主之下无复杂层级，所有狩众成员按实力与经验分为：新入（玩家初始）→ 正式 → 熟练 → 精锐 → 上位。玩家的故事线就是在夜狩众中成长的过程。

#### 势力特色

- 唯一的跨种族中立武装组织（成员来自所有种族）
- 规模小但个体质量高
- 拥有独立情报网络与各势力的非正式联系渠道
- 行动原则清晰：只处理"黑暗"相关威胁，不参与政治斗争

## 隐秘组织

### 暗星教团

**性质**：邪教组织/恐怖势力
**信仰**：崇拜暗星（第七星神），认为暗星复苏是世界"回归真实"的必然
**领导者**：黄泉返（よみがえり）——身份完全未知

暗星教团的存在从1.0版本起就通过碎片信息暗示，但其全貌至今未完全揭露。已知信息：
- 成员遍布各种族各势力（潜伏者众多）
- 拥有使用禁术的能力（尤其是暗星共鸣）
- 目标是加速暗星封印的瓦解
- 首领"黄泉返"从未公开现身，甚至不确定是一个人还是一个头衔

暗星教团的危险在于其成员往往在堕落前是正常的社会成员——医生、商人、甚至星读院的学者。这使得防范极为困难。

### 星继者

**性质**：神秘个体/命运选中者
**概念**：七个继承了七曜星神部分意志的个体

星继者并非组织，而是一种存在状态。传说中，每一代都会诞生七个与七曜星神产生特殊共鸣的个体。前六星的继者通常被视为英雄/天才，而第七星（暗星）的继者则被视为灾厄的预兆。

已公开的星继者相关信息极为有限：
- 星继者本人可能并不自知
- 觉醒过程不可控，通常在极端压力下触发
- 前六星继者觉醒后会获得对应属性的极致掌控力
- 暗星继者觉醒后的情况...是绝对机密

## 势力关系图

```
                    ┌─── 对立（权力争夺）───┐
                    │                        │
               星读院 ←── 警惕 ──→ 幻月社
                 │ \                      / │
                 │  \                    /  │
               监管   紧张            冷淡  中立
                 │     \            /      │
                 │      \          /       │
              潮音阁 ── 友好 ── 夜狩众     │
                 │                  \      │
                 │                   \     │
               中立                   中立  │
                 │                     \   │
                 │                      \  │
              夜之王庭 ── 对立 ── 星读院（同上）
                    \
                     ── 敌视 ── 暗星教团（全势力共同敌人）
```

**关系要点**：
- 星读院 vs 夜之王庭：最大的政治对立轴。权力结构、价值观、种族利益全面冲突。
- 星读院 vs 幻月社：互相警惕但避免正面冲突。白夜的存在让星读院忌惮。
- 潮音阁：最中立温和的调停者，与所有势力保持友好或中立。
- 夜狩众 vs 所有势力：保持等距离。接受各方委托但不偏袒。
- 暗星教团：所有势力的公共敌人，但各势力对其威胁程度的判断不同。

## 玩家与势力互动方式

### 按版本开放

| 版本 | 可互动势力 | 互动深度 |
|------|-----------|---------|
| 1.0 | 星读院、夜之王庭、夜狩众 | 任务委托、剧情对话 |
| 1.1 | 同上 | 新增：声望系统（好感度） |
| 1.4 | 新增：潮音阁 | 同上 |
| 2.0-2.2 | 同上 | 新增：势力抉择事件（影响主线走向） |
| 2.4 | 新增：幻月社 | 同上 |
| 3.0+ | 全部 | 新增：势力专属支线、阵营战争（PvP背景） |

### 互动机制

1. **声望（好感度）**：通过完成势力任务、做出符合势力价值观的选择来积累。高声望解锁独占奖励（装备/技能/剧情）。
2. **势力抉择**：主线特定节点会要求玩家在两个势力的立场之间选择。选择不会导致"断绝"，但会影响后续剧情展开。
3. **阵营战争**：3.0后开放的PvP内容，玩家可代表某一势力参与领地争夺。但这是"代理战争"——输赢不改变主线。
4. **个人立场**：玩家始终是夜狩众成员，与任何势力的关系都是"合作"而非"归属"。这是叙事前提，不可改变。

## 叙事注意事项

1. 五大势力无绝对善恶——每个势力都有合理的立场与不可忽视的缺陷
2. 暗星教团是唯一可以定性为"恶"的组织，但其基层成员中也有被蒙蔽/被迫的个体
3. 玩家不可"加入"任何势力（始终是夜狩众），但可以深度影响与各势力的关系
4. 各势力内部并非铁板一块——存在鸽派/鹰派、改革派/保守派等分歧
5. 势力间的冲突本质上是价值观与利益的冲突，不是"谁是坏人"的问题
