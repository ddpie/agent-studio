# 魔法与力量体系

## 根源：星力

夜见世界一切超自然力量的根源都是"星力"——七曜星神坠落时其本质碎片遗留在大地灵脉中的能量。星力并非凭空产生，而是从灵脉中汲取；灵脉也并非无限，而是以极缓慢的速度自然恢复。这是整个力量体系最基本的物理法则。

### 星力的属性

星力根据来源星神的不同，分为七种属性。前六种被称为"正属性"，第七种（源自暗星）被称为"阴属性"。

| 属性 | 对应星神 | 特性 | 色调 |
|------|---------|------|------|
| 焰 | 第一星·炎帝 | 高温/爆发/净化 | 赤橙 |
| 潮 | 第二星·海皇 | 流动/适应/治愈 | 靛蓝 |
| 风 | 第三星·天薙 | 速度/切割/传导 | 翠绿 |
| 地 | 第四星·岩神 | 防御/重力/固化 | 土金 |
| 雷 | 第五星·雷光 | 瞬发/麻痹/链接 | 紫电 |
| 冰 | 第六星·霜华 | 减速/冻结/保存 | 霜白 |
| 暗 | 第七星·暗星 | 侵蚀/变异/控制 | 深紫黑 |

**重要**：正属性之间不存在"克制"关系。六种正属性是平等的，只是特性不同。唯一的对立轴是"正属性 vs 阴属性"。

### 正属性 vs 阴属性

- 正属性：来源于前六星，是"秩序"的力量。使用者精神越稳定、意志越明确，正属性越强。
- 阴属性：来源于暗星，是"混沌"的力量。使用者情绪越极端、欲望越强烈，阴属性越强。
- 两者在本质上是同源的（都是星力），但运作逻辑相反。
- 长期大量接触阴属性会导致"侵蚀"——身体与精神的不可逆变异。这是夜堕者产生的根本机制。

## 星辰之力

"星辰之力"是星力结晶体的叙事名称。在游戏系统中它对应的是高级货币/核心资源（钻石的叙事包装）。

### 物理形态

- 半透明结晶体，内部有微弱流动的光纹
- 大小从米粒到拳头不等，越大越稀有
- 天然产于"星穴"——灵脉能量特别密集的节点
- 颜色取决于属性：对应上表的色调，但多数星穴产出的是无色（未定属性）结晶

### 用途

- **修炼加速**：吸收星辰之力可以加速星力修炼进度
- **术式刻录**：高阶术式需要以星辰之力为媒介才能稳定固化
- **装备强化**：武器和防具可以嵌入星辰之力以获得属性加成
- **设施运转**：大型设施（如星见塔的星力监测网）需要持续消耗星辰之力

### 经济意义

星辰之力是夜见世界最珍贵的通用资源，也是各势力争夺的核心。星穴的控制权直接关系到势力的实力增长。星读院通过"星力管制令"试图垄断星辰之力的分配，是其与其他势力冲突的重要原因之一。

## 四大流派

夜见世界的力量修行存在四种主要流派，各流派与种族紧密绑定，体现了不同种族对星力本质的独特理解。

### 一、术式道（じゅつしきどう）

**主修种族**：人类
**核心理念**：将星力运用"编程化"——通过精确的符号、纹路、手势组合来调动和定向星力

#### 原理

人类的星力亲和度中等，无法像鬼族那样直接以肉体承载巨量星力。因此人类发展出了"术式"这一中介系统——类似于编程语言之于计算机。术式由三部分构成：

1. **星纹**（媒介）：刻画在纸张/武器/身体上的特定纹路，用于引导星力流向
2. **指序**（触发）：特定的手势/动作序列，用于激活星纹
3. **意念**（方向）：施术者的精神集中，决定术式的效果指向

#### 特点

- 最"科学化"的流派——可以记录、传授、复制、改良
- 上限取决于术式设计的精巧度和施术者的星力总量
- 准备时间较长（需要绘纹/摆指序），但效果稳定可控
- 是唯一可以被其他种族部分学习的流派（基础术式不依赖种族天赋）

#### 阶段

| 阶段 | 特征 |
|------|------|
| 入门 | 使用预制星纹卡片，效果弱但简单 |
| 中级 | 即时绘纹（空中/武器上），效果中等 |
| 高级 | 内刻星纹（身体内部），无需外部媒介 |
| 极致 | "无式"——不需要任何外在形式，纯以心念驱动术式（传说级，极少数人类达到） |

---

### 二、鬼力道（きりきどう）

**主修种族**：鬼族
**核心理念**：以自身肉体为星力的直接通道——不借助外部形式，将身体本身改造为"容器"与"武器"

#### 原理

鬼族的肉体天生拥有远超其他种族的星力耐受度。他们不需要术式作为中介，而是直接将星力灌注入肌肉、骨骼、皮肤中，使身体各部位获得超常能力。这个过程被称为"鬼力觉醒"——从局部（如双臂强化）逐渐扩展到全身的过程。

#### 鬼力觉醒

觉醒并非一次性事件，而是持续一生的渐进过程：

1. **初觉**：某一肢体/器官首次成功承载超量星力。通常伴随剧烈疼痛。多数鬼族在青年期经历。
2. **半身觉**：上半身或下半身完全觉醒。战斗力产生质变。
3. **全觉**：全身所有组织都能承载星力。达到此阶段的鬼族极少。
4. **永觉**：极致状态——身体本身成为星力结晶化的存在，不再衰老。目前已知仅鬼王岩场暁达到。

#### 特点

- 爆发力极强，近战无敌
- 无需准备时间——想用就用
- 代价是身体承受的负荷——过度使用会导致"鬼蚀"（组织坏死）
- 完全无法远程攻击（这是鬼族最大的战术弱点）
- 不可教授给其他种族（依赖鬼族特有的体质基因）

---

### 三、幻梦道（げんむどう）

**主修种族**：狐族
**核心理念**：操纵"认知"——不改变物理现实，而是改变目标对现实的感知方式

#### 原理

狐族认为"现实"是心识的投射。如果能改变某人的心识状态，那么对该人而言，现实就已经改变了。幻梦道不创造物理力量，而是直接作用于目标的感知系统——使其看到不存在的事物、听到虚构的声音、甚至感受到并不存在的疼痛。

#### 核心概念：幻域

"幻域"是狐族独有的存在——一个由集体心识构建的半独立空间。可以理解为"共享的梦境"。高阶狐族可以将目标拉入幻域中，在其中制定完全不同的物理法则。幻域中受到的精神伤害会部分反馈为现实中的肉体伤害（反之不然）。

#### 限制

- 对精神力（意志力）高的目标效果减弱——极端坚定的意志可以直接看破幻术
- 只能影响"有意识的存在"——对无生命物体完全无效
- 狐族自身也可能迷失在幻域中（尤其是新月夜）
- 不能直接造成物理伤害——所有"伤害"都是通过欺骗感知间接实现的

#### 阶段

| 阶段 | 能力 |
|------|------|
| 单幻 | 影响单一感官（如只能制造视觉幻象） |
| 复幻 | 同时影响多种感官 |
| 全幻 | 构建完整的虚拟环境 |
| 入域 | 创造/维持幻域 |
| 织梦 | 在幻域中制定规则（传说级） |

---

### 四、潮声道（ちょうせいどう）

**主修种族**：海民
**核心理念**：通过声波与灵脉产生共振，以"聆听"和"发声"作为力量的输入与输出

#### 原理

海民相信灵脉并非静态存在，而是持续以特定频率振动的能量流。他们天生具备感知这种振动的器官（内耳深处的"灵听觉"）。潮声道的修行就是精确掌握灵脉振动的频率，然后以自身发出的声波与之"共振"或"干涉"，从而操控星力。

#### 核心能力

1. **聆听**（被动）：感知周围灵脉的振动频率。修行越深，聆听范围越广、精度越高。高阶海民可以通过聆听判断对方的情绪状态、健康状况甚至星力总量。
2. **共鸣**（主动-增幅）：发出与灵脉同频的声波，增幅灵脉输出。用于治疗、强化、加速等正面效果。
3. **干涉**（主动-抑制）：发出与灵脉反频的声波，抑制或打乱灵脉输出。用于削弱敌人、封印能力、创造"沉默区"。
4. **谐唱**（集体）：多名海民同时发声，形成和声结构，产生数倍于单人的效果。潮音阁最强力的集体术式都是谐唱型。

#### 特点

- 攻击距离极远（声波传播范围）
- 群体辅助/治疗能力最强
- 极度依赖环境——在真空/声波被屏蔽的环境中完全失效
- 个体爆发力不如其他三流派
- 对声波敏感的种族（如鬼族在赤月态时）效果加成

## 五禁术

以下五种术式被夜见世界所有势力共同列为"禁术"——不是因为它们弱，恰恰因为它们太强且代价太过惨烈。使用禁术在多数势力中是死罪。

### 一、还魂术

**效果**：将死者的灵魂从黄泉比良坂召回，重新注入肉体
**代价**：施术者寿命折半 + 被召回者永久丧失一种感官
**为何禁止**：违反"死亡不可逆"的根本法则。且被召回者的精神状态极不稳定，有高概率堕落为夜堕者。
**备注**：历史上已知的还魂术成功案例不超过三起，全部以悲剧收场。

### 二、魂缚术

**效果**：将目标的灵魂从肉体中剥离，封入指定容器（武器/宝石/傀儡等）
**代价**：施术者每封缚一个灵魂，自身精神年龄加速十年
**为何禁止**：被封缚者的意识不会消失——他们被困在容器中，清醒地感受时间流逝却无法行动。本质上是对灵魂的酷刑。
**备注**：暗星教团被怀疑大量使用此术制造"灵魂兵器"。

### 三、暗星共鸣

**效果**：主动与暗星的残余意志建立连接，获取暗星级别的阴属性力量
**代价**：每次共鸣都会加深阴属性侵蚀，不可逆
**为何禁止**：这是"成为夜堕者"的快车道。且共鸣过程中施术者的行为不受自己控制——暗星意志会短暂接管其身体。
**备注**：暗星教团的核心仪式。

### 四、梦蚀之法

**效果**：将目标拉入特殊幻域中，在其中反复经历精神创伤直至心智崩溃
**代价**：施术者必须全程陪同在幻域中（自身精神也承受压力）
**为何禁止**：本质是精神层面的酷刑与谋杀。被梦蚀者即使肉体完好，精神也已完全破碎——比杀死更残忍。
**备注**：狐族内部最大的禁忌。传说中曾有狐族长老对敌人使用此术，之后自己也陷入了无法醒来的梦境。

### 五、永觉代价

**效果**：通过特殊仪式强制触发"永觉"状态（正常情况下永觉需要数百年修炼才可能自然达到）
**代价**：仪式需要消耗三名第三阶以上鬼族的全部鬼力（施术后他们将沦为普通人且无法恢复）
**为何禁止**：本质是牺牲同族来强化个体。违背了鬼族"以自身力量证明"的根本价值观。
**备注**：鬼族历史上确有鬼王通过此法登位。这是王庭内部最敏感的话题。

## 六阶等级

所有种族的力量水平使用统一的"六阶"体系衡量，这是一个跨流派的通用标准。

| 阶级 | 名称 | 特征 | 大致人口比例 |
|------|------|------|-------------|
| 第一阶 | 星感 | 能感知星力存在，但无法主动运用 | 约60%人口 |
| 第二阶 | 星引 | 能引导少量星力，掌握基础术式/能力 | 约25%人口 |
| 第三阶 | 星操 | 熟练运用星力，可独立完成中等难度战斗 | 约10%人口 |
| 第四阶 | 星驭 | 高度掌控星力，各势力核心战力 | 约4%人口 |
| 第五阶 | 星主 | 对星力有近乎完美的掌控，势力领袖级 | 不足0.5% |
| 第六阶 | 星神遗 | 传说级——接近星神遗留意志的存在 | 极其罕见/可能不存在 |

### 升阶规则

- 每阶之间存在明确的"壁垒"——不是渐进提升而是质变突破
- 壁垒突破需要特定条件（因流派而异），不是单纯的星力积累
- 越高阶突破越困难，且失败可能导致退阶（不可逆的能力下降）
- 第五阶到第六阶的壁垒被认为"可能根本不存在突破方法"
- 等级差距体现为压倒性优势：正常情况下高一阶者可以完克低一阶者

### 种族差异

| 种族 | 容易达到 | 难以突破 | 天花板推测 |
|------|---------|---------|-----------|
| 人类 | 第二阶 | 第四→五阶 | 极少数第五阶 |
| 鬼族 | 第三阶 | 第五→永觉 | 永觉≈第五阶+ |
| 狐族 | 第三阶 | 未知 | 白夜可能第五阶以上 |
| 海民 | 第二阶 | 第四→五阶 | 与人类接近 |
| 夜堕者 | 不定 | 不定 | 失控状态下可短暂爆发至高阶 |

## 八条核心法则

以下八条法则是魔法与力量体系的基石，也是审核内容时判断"是否合理"的根本参考。任何游戏内容都不得违反这些法则。

### 法则一：能量守恒

**表述**：星力不会凭空产生，必须从灵脉/星辰之力中汲取。使用必然消耗，消耗后需要恢复时间。

**审核含义**：
- 不可出现"无限释放术式"的描述
- 长时间战斗必须有体力/星力下降的表现
- "以少胜多"必须有代价或特殊条件支撑

### 法则二：属性不可改

**表述**：个体的星力属性亲和在出生时就已确定，无法后天改变。可以学习多种属性的基础运用，但"核心属性"终身不变。

**审核含义**：
- 角色不可突然变更主属性
- "双属性天才"可以存在但极其罕见（需有设定支撑）
- 不可出现"通过修炼获得新属性"的描述

### 法则三：等级壁垒

**表述**：阶级之间存在本质差距。在无外力干涉的正常对抗中，高一阶者对低一阶者有压倒性优势。

**审核含义**：
- 第二阶不可正面击败第四阶（除非有极特殊的情节装置）
- "越级战斗"只能存在于相邻阶级之间，且需要付出巨大代价
- 主角的成长速度可以快但不可跳阶

### 法则四：禁术必有代价

**表述**：禁术之所以为禁，是因为其代价不可承受。任何使用禁术的情节都必须明确展示代价。

**审核含义**：
- 不可出现"无代价使用禁术"的情况
- 代价必须是实质性的、不可逆的
- 不可将禁术的代价轻描淡写或事后消除

### 法则五：环境依赖

**表述**：星力的效能受环境影响。灵脉丰富的地方星力充足，灵脉贫瘠或被污染的地方星力减弱。

**审核含义**：
- 在"沉默区"中所有星力都应失效
- 在灰烬森中正属性会被干扰
- 不同区域应有不同的环境效果

### 法则六：种族天赋不互换

**表述**：鬼力觉醒、幻域操控、灵脉聆听——这些能力与种族基因绑定，不可跨种族传授或学习。

**审核含义**：
- 人类不可学会鬼力觉醒
- 非狐族不可进入幻域（被拉入除外）
- 海民的聆听能力不可被复制
- 唯一例外：术式道的基础部分可跨种族学习（因为它本质上是"工具"而非"天赋"）

### 法则七：月相强制

**表述**：月相对所有星力使用者产生强制影响。这不是可选的buff，而是环境级的、无法屏蔽的系统性变化。

**审核含义**：
- 满月时所有正属性+15%是"事实"不是"如果愿意"
- 新月时阴属性增强也是强制的——这意味着新月是夜堕者最危险的时间
- 不可出现"免疫月相影响"的能力（除非是极特殊的设定级例外）

### 法则八：死亡不可逆

**表述**：在夜见世界中，死亡是终极的、不可逆转的。灵魂前往黄泉比良坂后不可返回（还魂术是禁术且有极端代价正因如此）。

**审核含义**：
- 已确认死亡的角色不可复活
- "假死"可以作为剧情装置但需要合理铺垫
- 不可出现"轻松复活"的机制或描述
- 黄泉比良坂的探索不等于"能把人救回来"

## 战斗系统的叙事表达

在撰写战斗相关内容时，以下是将游戏机制转化为叙事描述的参考：

| 游戏机制 | 叙事表达 |
|---------|---------|
| HP | 以伤口描写、疲劳程度、意识清晰度表现 |
| MP/星力值 | 以呼吸急促、星纹暗淡、动作迟缓表现 |
| 暴击 | 以找到破绽、完美时机、意志爆发表现 |
| 属性克制 | 本系统不存在属性克制，但环境因素可影响效果 |
| 等级压制 | 以压迫感、无法抵抗的重量感、绝望感表现 |
| buff/debuff | 以环境描写（月光增强）、状态描写（身体发光/发冷）表现 |
| 死亡 | 必须严肃对待——不是"倒下"而是"终结" |

## 补充：力量体系的审核参考

当审核游戏内容是否符合力量体系设定时，按以下优先级判断：

1. **是否违反八条核心法则？** → 违反则一票否决
2. **是否符合种族/流派限制？** → 不符则需修改
3. **是否有足够的代价/条件支撑？** → 不足则需补充
4. **是否与已公开的角色实力匹配？** → 不匹配则需调整
5. **是否过度或不足描写战斗？** → 根据场景类型调整详细度

以上规则适用于所有对外输出内容，包括但不限于：主线剧情、支线剧情、角色台词、物品描述、NPC对话、活动剧情。
