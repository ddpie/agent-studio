## 使用规则

1. **翻译时必须使用本表译名**，不得自行创译或使用近义词替代
2. 表中未收录的新术语，翻译前须提交审核确认
3. 日语保留原始假名读音标注（用于语音场景）
4. 英语采用音译（日式读音）为主、意译为辅的策略
5. 韩语采用日语读音的韩式转写
6. 变量占位符（如 `{player_name}`）不翻译，原样保留
