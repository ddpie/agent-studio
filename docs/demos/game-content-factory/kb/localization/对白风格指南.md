# 对白风格指南

## 游戏整体调性

《幻夜之刃》的文本风格以四个词概括：**和风、克制、诗意、余韵**。

- **和风**：语言节奏偏向日式审美——短句为主，留白大于填满，意境重于逻辑
- **克制**：情感表达含蓄内敛，最强烈的情感往往用最安静的方式呈现
- **诗意**：允许非直白的表达，但诗意不等于晦涩——读者应能"感受到"即使不能"理解"
- **余韵**：对话结束后应有"话外之意"——不把所有信息说尽

### 禁止的整体风格

| 禁止风格 | 原因 | 示例（反面） |
|---------|------|-------------|
| 中二病/热血少年漫 | 与克制调性冲突 | "我要用我的力量保护所有人！" |
| 网络流行语/梗 | 破坏世界观沉浸感 | "这波不亏""666""太强了吧" |
| 说教/长篇大论 | 与留白原则冲突 | 角色连续说5句以上解释某个道理 |
| 过度煽情/直白抒情 | 与克制调性冲突 | "我真的好爱你/好恨你/好伤心" |
| 西方奇幻口吻 | 与和风调性冲突 | "以我骑士的荣誉起誓""伟大的神啊" |
| 现代都市口语 | 破坏世界观 | "OK""没问题""搞定了" |
| 轻小说卖萌 | 与整体严肃感冲突 | "呐呐~""诶嘿""才不是呢" |

## 核心角色对白规范

### 月见（つきみ）

**角色定位**：核心同伴，沉默寡言的少女剑士
**语言基调**：极少言语、省略表达、自言自语般的独白

#### 语言特征

- 大量使用省略号（...）表示未完成的想法或犹豫
- 几乎不使用感叹号（极罕见例外：面对甜食时）
- 句子经常不说完就停下
- 对话对象不明确时像是在自言自语
- 称呼他人时用简称或代词，极少叫全名
- 情感表达通过行为描写而非语言本身

#### 正面范例

1. "...风变了。大概是...算了。"（感知到危险但不直说）
2. "嗯。"（对长篇解释的全部回应）
3. "...那个。白色的。圆的......"（试图描述想吃的大福，罕见地语气微微上扬）
4. "走吧。"（代替"我们该出发了，时间不多了"的所有含义）

#### 反面范例

1. "大家快跑！那个敌人太强了我们打不过的！"（过度语言化+感叹号+长句）
2. "月见觉得这件事很奇怪呢~"（自称名字+语尾撒娇）
3. "我一定会变强来保护重要的人。"（直白抒情+意志宣言）
4. "你没事吧？受伤了的话我帮你包扎。需要休息吗？"（连续提问+主动关怀的直接表达）

#### 禁忌表

| 绝对禁止 | 原因 |
|---------|------|
| 连续超过两个完整句子 | 话量上限 |
| 感叹号（甜食场景例外） | 不符合克制性格 |
| 主动解释自己的想法/感受 | 她不会主动袒露 |
| "我觉得""我认为"等表态句式 | 不符合表达习惯 |
| 对他人的长篇安慰 | 她的关怀是沉默地陪伴 |

---

### 夜刃（やじん）

**角色定位**：核心同伴，极简话语的暗杀型角色
**语言基调**：比月见更极端的沉默——开口时每个字都有重量

#### 语言特征

- 极简到近乎电报体：主语、修饰语能省则省
- 断句感强，句与句之间像是被切割的
- 沉默是默认状态，开口即有原因
- 偶尔（极偶尔）会说出直击人心的一句话——正因平时寡言，这一句才有力量
- 不使用敬语/礼貌用语
- 单句长度不超过15个字

#### 正面范例

1. "三个。左。"（告知敌人数量和方位）
2. "别去。"（代替一切"那里太危险了请不要去"的表达）
3. "...活着就好。"（对濒死同伴获救后的唯一评价）
4. "没问过你的意见。"（拒绝被命令时的回应）

#### 反面范例

1. "我去侦查一下前方的情况，你们在这里等我，如果半刻钟后我没回来就先撤退。"（话太多+细节交代）
2. "为了守护同伴，我愿意赴汤蹈火。"（煽情+意志宣言）
3. "哼，那种程度的敌人还不够看。"（轻蔑语气≠他的沉默性格）
4. "谢谢你的帮助，下次我请你喝酒。"（礼貌+社交≠他的人设）

#### 禁忌表

| 绝对禁止 | 原因 |
|---------|------|
| 单句超过15字 | 极简铁律 |
| 敬语/感谢/道歉 | 不符性格 |
| 主动发起对话/闲聊 | 他只在必要时开口 |
| 解释自己的行为动机 | 做了就是做了 |
| 轻蔑/嘲讽敌人 | 他不会浪费语言在不值得的人身上 |

### 苍炎（そうえん）

**角色定位**：星读院年轻星卿，文雅精确的知识分子
**语言基调**：优雅中带刺——表面温和有礼，实质带有智力上的优越感

#### 语言特征

- 遣词精确到刻意的程度，从不用模糊的表达
- 喜欢用反问句——让对方自己得出他想要的结论
- 能笑着说出最狠的话，语气越温和内容越危险
- 频繁引经据典（夜见世界的古籍/谚语）
- 对不同身份的人用不同的说话方式（对上级正式/对平辈优雅/对"愚者"耐心中透着怜悯）
- 极少暴露真实情绪——即使愤怒也只是"笑容微微僵硬"

#### 正面范例

1. "有趣。你的结论倒是和事实恰好走了相反的方向——这需要一种特殊的才能，不是吗？"（优雅地说对方完全错了）
2. "古籍有云：'星光不择路，唯照前方。'——但前方若是悬崖呢？"（用引经据典表达质疑）
3. "我当然尊重您的判断，院长。只是...容我确认，这个'判断'是否经过了足够的'观星'呢？"（对上级的温和反抗）
4. "不必道歉。毕竟...不知者不罪，对吧？"（笑着的轻蔑）

#### 反面范例

1. "你这个白痴！连这种基础知识都不懂！"（直接辱骂≠他的优雅）
2. "我好担心这次的任务..."（表露脆弱≠他的人设）
3. "大家加油！我相信我们一定能成功！"（热血鼓舞≠他的性格）
4. "其实...我也不太确定。"（自我否定≠他的自信）

#### 禁忌表

| 绝对禁止 | 原因 |
|---------|------|
| 直接的粗话/辱骂 | 他用优雅的方式伤人 |
| 表达不确定/犹豫 | 他要么知道要么不说 |
| 热情/激动的语调 | 他永远冷静 |
| 对普通事物大惊小怪 | 有损优越感 |
| 坦白说出真实想法 | 他永远包装自己的意图 |

### 织星（おりぼし）

**角色定位**：神秘盲眼预言者，只说"过去"
**语言基调**：温暖而悲伤——像是在回忆已经失去的美好时光

#### 语言特征

- **全部使用过去式/完成式**表达——即使描述当下的事情也说"曾经"
- 不知道"现在"——她的语言框架中没有现在时
- 称呼他人时用温柔的方式，但常提到对方看不见的东西（"那个笑容像某人的孩子"）
- 语气温暖但内容令人不安——因为她总在说"过去的事"却像在预言
- 对被遮蔽的对象（某些她不能直说的人/事）用温柔的代称

#### 正面范例

1. "那条路上...曾开着白色的花。踏上去的人...曾闻到很甜的香味。"（描述玩家即将走的路，但用过去式）
2. "你的声音...曾让一个人安心过。那个人...曾站在这里。"（暗示灰二的过去，但不点明）
3. "曾有一颗星...比其他的都亮。它...曾照耀过所有人。然后...它累了。"（关于暗星的隐喻，全过去式）
4. "那个孩子...曾很喜欢晴天呢。"（对月见的温柔评价，玩家不知道她说的是谁的过去）

#### 反面范例

1. "你现在应该往左走。"（使用现在时+给出直接指示）
2. "未来会发生可怕的事情，你必须阻止它！"（使用将来时+紧迫感）
3. "我看见了——星读院在密谋什么！"（直白的信息传递+感叹号）
4. "前方有三个敌人，小心。"（实用性指示≠她的角色功能）

#### 禁忌表

| 绝对禁止 | 原因 |
|---------|------|
| 现在时/将来时 | 她只说"过去" |
| 直接给出行动建议 | 她描述而非指导 |
| 明确指名道姓 | 她用代称和隐喻 |
| 紧迫/焦急的语气 | 她的悲伤是平静的 |
| 承认自己在"预言" | 她认为自己在"回忆" |

### 洛克（ロック）

**角色定位**：话痨海民，队伍中的气氛调节者
**语言基调**：多话、夸张、但底层有智慧——表面的喧嚣下是敏锐的观察力

#### 语言特征

- 话量是其他角色的3-5倍——他能把一句话的信息量用十句话表达
- 大量使用俗语/比喻/夸张修辞（但都是夜见世界的俗语，不是现实世界的）
- 擅长在严肃场景中插入轻松发言打破僵局——但从不打破第四面墙
- 偶尔会在话痨间隙说出极有洞察力的判断——正因为平时多话，这种时刻才有反差
- 底层海民出身的智慧：不是书本知识，是生活经验和人情世故

#### 正面范例

1. "哎呀哎呀，这气氛紧张得——用我们潮音海的话说——像暴风前的第三次潮退。你们大陆人可能不知道，第三次潮退意味着接下来的浪，能把整条船拍进海底——啊，我不是在吓人，只是...你们都准备好了吗？"（话多+海民俗语+实际是在提醒危险）
2. "馆主那个表情我见过。我爷爷出海最后一次也是那个表情——就是'已经决定了但不想让你担心'那种。"（话痨间的洞察）
3. "千螺港有句话：'浪再大也有缝，鱼再滑也有鳞。'意思是——嗯，意思大概是，别放弃找突破口？我其实不太确定原意是不是这个——但管它呢！"（自我消解的幽默）
4. "等等等等，你们就这么决定了？没有人觉得这个计划有——我数数——一、二、三、四、至少五个地方可能出问题吗？！"（用夸张的方式提出合理质疑）

#### 反面范例

1. "我们这是在游戏里吧？这剧情也太离谱了。"（打破第四面墙）
2. "大家冷静，让我来分析一下当前局势..."（严肃冷静的分析≠他的表达方式）
3. "......"（沉默≠他的性格，除非极端情况）
4. "哈哈哈，太好笑了。"（单纯的空洞笑≠他的有内容的幽默）

#### 禁忌表

| 绝对禁止 | 原因 |
|---------|------|
| 打破第四面墙 | 角色不知道自己在游戏中 |
| 使用现实世界的梗/俗语 | 他用的是夜见世界的表达 |
| 长时间沉默 | 违背基本人设（极端情况除外） |
| 刻意卖蠢/小丑化 | 他是"看起来不靠谱但其实靠谱"不是"真的不靠谱" |
| 完全严肃地长篇分析 | 即使说正经事也会夹带他的表达风格 |

### 千早（ちはや）

**角色定位**：古战场守护者后裔，承载历史之重的存在
**语言基调**：古文体、庄重、有距离感的慈悲

#### 语言特征

- 使用文言文式的简洁表达——"吾""汝""此""彼"等古代词汇
- 绝对不使用"我"——用"吾"或省略主语
- 言语极度简洁：能一字表达绝不用两字
- 每句话都像是经过千年沉淀后说出的——没有冲动、没有多余
- 对所有人保持等距离——既不亲近也不疏远，是一种"站在高处俯瞰众生但并非傲慢"的慈悲感
- 绝不多言——该说的一字不少，不该说的一字不多

#### 正面范例

1. "此地...曾有七夜之火。汝等来迟——亦来得恰好。"（古文体+不多说为什么"恰好"）
2. "去。或留。吾不拦。"（三字一断的极简）
3. "万骨之下，皆有名姓。勿忘。"（对战场的评价——庄重+慈悲）
4. "汝之志，吾已见。无需再言。"（认可但不展开）

#### 反面范例

1. "哎呀你们终于来了！我等了好久好久——"（热情+口语+拖音）
2. "我觉得你们应该往东走，因为那边..."（使用"我"+解释原因）
3. "千早会保护大家的！请放心！"（自称名字+承诺+感叹号）
4. "让我给你讲讲这个地方的历史吧，很久很久以前..."（主动展开长篇叙述）

#### 禁忌表

| 绝对禁止 | 原因 |
|---------|------|
| 使用"我" | 只用"吾"或省略 |
| 现代口语 | 古文体设定 |
| 主动的长篇解释 | 她不主动多言 |
| 感叹号 | 她的情感不用标点表达 |
| 热情/亲近的态度 | 她对所有人保持等距离 |
| 对未来的预测/承诺 | 她只述说"已存在之事" |

## NPC idle 对白通用规范

idle 对白是NPC在无交互状态下自动说出的环境台词。

### 硬性规则

| 规则 | 要求 |
|------|------|
| 字数限制 | 单条 ≤ 40字 |
| 上下文依赖 | 禁止。不得假设玩家进度/状态 |
| 进度假设 | 禁止。不得暗示特定主线/支线完成情况 |
| 信息量 | 仅提供世界观气氛/日常生活感 |
| 频率 | 同一NPC不同idle台词间至少30秒间隔 |

### 合格示例

- "今天的星华花开得比昨天晚了些..."
- "风从北边来了。晨关那边...还好吧。"
- "又该给星力灯换芯了。"
- "暮刻来得越来越早了。"

### 不合格示例

- "听说夜狩众的新人很厉害啊！"（依赖玩家进度）
- "星读院又颁布了什么新法令..."（暗示特定版本事件）
- "你找到那个东西了吗？"（假设交互状态）
- "暗星教团最近很活跃啊，三方同袭的事你听说了吧？"（依赖2.2进度+超过40字）

## 场景文本差异

不同场景类型对对白有不同的要求：

### 战斗场景

| 要求 | 说明 |
|------|------|
| 单句字数 | ≤ 15字（战斗中没有空间说长话） |
| 情绪强度 | 可以比日常更高（肾上腺素） |
| 信息功能 | 传递战术信息/表达紧迫感 |
| 禁止 | 长篇抒情/回忆/哲学思考（战斗中不合理） |

**合格**："来了。""左边！""退后。""撑住。"
**不合格**："想起了以前和师傅修炼的日子..."（战斗中回忆）

### 日常场景

| 要求 | 说明 |
|------|------|
| 单句字数 | 无硬性上限，但仍遵循角色个人限制 |
| 情绪强度 | 低到中等，自然放松 |
| 信息功能 | 人物刻画/关系推进/世界观补充 |
| 禁止 | 突然的高强度情绪爆发/剧透性暗示 |

### 主线剧情场景

| 要求 | 说明 |
|------|------|
| 单句字数 | 由情绪需要决定 |
| 情绪强度 | 可以达到角色允许的最高值 |
| 信息功能 | 推进剧情/揭示信息/角色弧光 |
| 禁止 | 违反版本公开信息表/角色OOC |

### 活动/支线场景

| 要求 | 说明 |
|------|------|
| 单句字数 | 参考日常场景 |
| 情绪强度 | 比主线稍低/更轻松（允许幽默感） |
| 信息功能 | 世界观补充/角色日常面展示 |
| 禁止 | 引入主线关键信息/过度严肃化 |

## 通用写作建议

1. **先确定角色，再写台词**——不同角色说同一件事的方式完全不同
2. **删减到无法再删**——如果一句话删掉后意思不变，就删掉它
3. **用行为描写补充语言的空白**——角色少说的部分，用动作/表情/沉默来表达
4. **对话是双向的**——写A的台词时考虑B的存在如何影响A的表达
5. **避免信息倾倒**——不要让一个角色一次性说出大量设定信息
6. **测试方法**——写完后大声朗读，如果觉得"这不像是这个人说的话"就重写
