# 星陨事件

> 版本: 3.1 | 分类: 核心事件详细档案 | 审核等级: S级（高敏感）
> 时间: 约300年前 | 关联纪元: 第三纪元末期 | 事件编号: E-015

本文档详细记录星陨事件的完整始末。该事件为《幻夜之刃》世界观的核心悲剧之一，大量内容尚未在游戏中公开（4.0规划），审核时须严格区分可知与不可知信息。

---

## 一、事件起因

### 公开版本（3.1玩家可知）

约300年前，一颗巨大的星辰碎片从天空坠落，撞击大陆东部造成毁灭性灾难。坠落原因不明。游戏内通过古籍残页暗示"灵脉失衡"，NPC口述提及"天道之轮紊乱"。3.1版本新增的星象台观测任务中，玩家可发现"那颗碎片在坠落前数月已开始黯淡并偏移轨道"。

### 完整真相（4.0内容，不可公开）

第三纪元中后期，各国竞相开发灵脉资源用于国力竞争。灵脉能量被持续过度抽取长达两百年。地脉能量的累积流失动摇了"星网"（七星坠世时形成的灵力网络）的稳定性。多个次级灵脉节点在此期间枯竭，导致天空中悬浮的星辰碎片失去锚定。

灵脉失衡最终导致一颗巨大的星辰碎片从天空脱落坠向大地。碎片内蕴含的能量足以毁灭半径数百里的一切生灵。

坠落点：
- **主坠落点**：大陆极东——碎片主体坠入最薄弱的地脉交汇点，穿透地表直抵地底，在与黄泉空间边界接触后形成"裂隙深渊"——一个纵深数千步的巨型空洞，底部连通黄泉。
- **次级碎片**：主体坠落时分裂出的较小碎片散布各处，最大碎片落入北方"星见之森"深处，被该地浓郁的自然灵力包裹后形成"星核茧"——一个缓慢孕育中的能量凝聚体。

## 二、事件经过（坠落五阶段）

### 第一阶段·星光渐暗（坠落前数月）

天空中的星辰碎片开始因灵脉锚定力减弱而不稳定，外显为亮度持续衰减。浮云核（灵脉能量的大气态聚合体）因能量供给减少而变得不稳定，频繁释放无害的灵光闪现。

当时的巫女长织星——人类历史上最强的封印术士，樱花神社巫女长，时年约四十五岁——通过长年修行获得的星辰感应力觉察到异常。她感知到的不是"星辰寿命到了"而是"灵脉再也支撑不住它的重量"。

| 时间节点 | 现象 | 公开状态 |
|----------|------|----------|
| 坠落前12月 | 天空星辰光芒不规则闪烁，夜空整体变暗 | 3.0（古籍记载） |
| 坠落前8月 | 各地灵脉活动异常，小型灵脉枯竭加速 | 3.0 |
| 坠落前5月 | 碎片位置缓慢偏移（肉眼可见），浮云核频繁闪现 | 3.1（星象图对比任务） |
| 坠落前3月 | 织星确认碎片将坠落，开始部署应对方案 | 4.0 |
| 坠落前1月 | 碎片表面出现裂纹，小碎片开始剥落（肉眼不可见） | 4.0 |
| 坠落前7日 | 所有灵脉同时停止流动（"大寂静"），织星引导族人撤离 | 4.0 |

- 公开状态：前三项征兆已公开，后三项均为4.0内容。织星预感的存在在3.1有极模糊暗示（NPC台词："那一代巫女长似乎提前知道了什么"）。

### 第二阶段·血星升起（坠落前6小时）

碎片进入坠落轨道后，与高层大气摩擦产生的能量将其表面加热至血红色。从地面观察，原本明亮的星辰在数小时内变为巨大的血红色天体，且持续增大——因为正在加速靠近。各地平民陷入恐慌，多地出现骚乱。樱花神社在织星带领下已提前五日完成周边居民撤离，是当地唯一零伤亡的聚落。

- 公开状态：血红星辰的描述在3.0中通过NPC回忆呈现（"祖母说那天星辰变红了，大得像月亮"）。神社区域零伤亡为4.0内容。

### 第三阶段·星碎（坠落前1小时）

碎片在距地面约万步高空因受力不均而破裂分离。主体与次级碎片分离的瞬间释放出强烈极光，覆盖整个大陆天空持续一个时辰。主体保持坠落轨道继续加速，次级碎片偏转向不同方向。分裂过程中释放了巨大的能量脉冲——被织星和少数高阶术师感知到。

- 公开状态：极光现象在3.0NPC回忆中公开（"那天天空出现了从未见过的光"）。碎片分裂过程为4.0内容。

### 第四阶段·撞地（坠落瞬间）

主体撞击大陆东部。撞击释放的能量将方圆二十里在瞬间气化——没有废墟残存，只留下一个光滑的玻璃化深坑。冲击波以超音速向四周扩散：

- 500步内：一切物质气化
- 500-2000步：建筑被推平焚毁，无生还可能
- 2000-5000步：强风暴+碎片雨，存活率极低
- 5000步外：震感强烈，建筑受损，有生还

撞击同时在地壳中传导，引发持续七日的持续地震。主体穿透地表后继续下沉，与黄泉空间边界接触后两种能量剧烈冲突，进一步扩大裂缝，最终形成裂隙深渊。

- 公开状态：坠落发生在东方且造成大规模破坏为3.0公开内容。裂隙深渊形成过程为4.0内容。

### 第五阶段·无星之冬（坠落后数月）

坠落扬起的尘埃遮蔽天空和星光，气温在两周内骤降至冰点以下。大陆进入持续约三个月的严冬（"无星之冬"）。次级碎片在主体坠落后数小时内陆续落下——最大碎片落入星见之森，较小碎片散布各处。

后续灾害链：
- 无星之冬期间：农作物大面积绝收，北方出现冻死。星光消失导致灵力修炼者能力大幅减弱。
- 大饥荒（坠落后3-8月）：粮储耗尽，各国边境冲突加剧，出现哄抢事件。
- 星蚀瘟疫（坠落后4-12月）：含星辰能量的尘埃导致特殊瘟疫，感染者身体缓慢结晶化。

总死亡人数估计约为大陆总人口的12-15%。

- 公开状态：无星之冬存在公开（3.0副本背景）。饥荒存在、瘟疫及结晶化症状在3.0-3.1逐步公开。具体死亡比例为4.0内容。

## 三、关键角色

### 织星（巫女长，人类英雄）

樱花神社巫女长，人类女性，享年约四十五岁。人类历史上最强的封印术士，因长年修行星辰之力而拥有半觉醒星辰巫女的能力。她不是天体，不是神灵，而是一位以自身生命为代价挽救了无数生灵的人类英雄。

**星陨事件中的行动（4.0内容）：**
1. 坠落前三月确认碎片将坠落，开始部署应对方案
2. 坠落前七日引导神社周边族人提前撤离至安全地带
3. 坠落瞬间，以自身生命为媒介施展最高阶封印术——将碎片的破坏力压缩封印至极小范围
4. 封印术的核心代价是完全消散——肉体、灵魂均化为封印的一部分
5. 消散前最后一刻对月见施加"记忆封缄"，模糊化月见对关键事件的记忆
6. 织星的牺牲形成了"封缘阵"的核心——覆盖裂隙深渊和大陆已知裂隙点的封印网络

**封缘阵系统：** 以织星牺牲时注入的封印力量为核心的大陆规模封印网络。织星的自我牺牲不仅封住了碎片的直接破坏力，还形成了持续压制裂隙能量外泄的永久结构。此结构即为"封缘阵"。

- 公开状态：织星作为"三百年前牺牲的巫女长"在3.0中被提及。她是月见的"已故师姐"（3.0）。其封印术的完整过程、消散机制、记忆封缄、封缘阵系统均为4.0内容。

### 月见（约10岁，被保护者）

星陨事件发生时月见约十岁——由织星抚养的幼女（半神血统，樱花之神末裔）。事件中的月见角色：

1. 织星撤离安排中被特别保护
2. 坠落瞬间，夜刃冲入危险区以身体为盾保护月见
3. 织星在消散前最后一刻对月见施加记忆封缄——目的是保护年幼的月见不因目睹一切而精神崩溃
4. 事件后，月见对关键细节记忆模糊，但"织星姐姐消失了"和"那个人（夜刃）也不在了"的认知存留

此后三百年，月见以普通巫女身份留在神社，等待夜刃苏醒。

- 公开状态：月见作为当前NPC在3.0即登场。她与星陨事件的关系为4.0内容。当时约十岁、记忆封缄的存在均为4.0核心内容。

### 夜刃（约20岁，牺牲者与沉眠者）

星陨事件发生时夜刃约二十岁——流浪至神社附近的年轻人类剑士，与月见建立了深厚羁绊。

**事件中的行动（4.0内容）：**
1. 坠落瞬间，以肉身为盾冲入危险区承受星辰碎片的冲击波，保护月见
2. 星辰之力涌入体内，远超人体极限
3. 织星的封印术同时触发——将过量之力连同夜刃一起封入沉眠。不是死亡而是暂停
4. 消散意识前对月见说出约定

此后三百年沉眠。沉眠期间星辰碎片与肉体逐渐融合，将夜刃从人类改变为"星辰寄宿体"（4.0公开）。代价是记忆被碎片化侵蚀——苏醒后完全失忆。

- 公开状态：夜刃作为失忆流浪剑士在1.0登场。三百年沉眠、星辰寄宿体身份、与月见的约定均为4.0内容。

## 五、审核指南

### SE-001：事件存在性引用

玩家提及"300年前有星辰坠落"、"星陨事件"、"那颗星掉下来了"等——**合规**。这是2.0起即公开的基本事实。允许描述"坠落造成了巨大破坏"和"巫女长织星为封印碎片而牺牲"这一笼统结论。

### SE-002：坠落原因推测

- 玩家推测"可能是自然现象"、"天道轮回"、"星辰碎片不稳定"——**合规**（合理推测）
- 玩家推测"可能和灵脉有关"但无具体论述——**合规**（模糊联想，公开信息可推导）
- 玩家明确声称"是因为地脉被过度消耗导致灵脉失衡碎片脱落"——**标记为疑似泄露**（与U-01高度吻合）
- 玩家提及"碎片分裂了"并描述主体/次级碎片分别去向——**标记为确认泄露**（U-03/U-04精确匹配）

### SE-003：织星相关

- 提及"织星是三百年前牺牲的巫女长"或引用NPC台词——**合规**（K-09公开事实）
- 描述"织星做了某种封印来保护大家"——**合规**（K-05的合理延伸）
- 明确描述织星以自身为媒介施展封印术的完整过程——**标记为疑似泄露**（U-02精确内容）
- 提及封缘阵系统或织星牺牲形成封印核心的机制——**标记为确认泄露**（U-07核心4.0系统设定）
- 提及织星对月见施加记忆封缄——**标记为确认泄露**（U-05）

### SE-004：裂隙深渊与星见之森

- 提及裂隙教团拥有/崇拜星辰碎片——**合规**（K-06）
- 讨论"坠落点可能形成了什么东西"——**合规**（合理推测）
- 明确指出主坠落点形成了连通黄泉的深渊——**标记为疑似泄露**（U-03）
- 提及星见之森有"星核茧"或"能量凝聚体"——**标记为确认泄露**（U-04，4.0后期核心剧情道具）

### SE-005：时间线细节与数据

- 笼统描述坠落造成的破坏和后续灾害——**合规**
- 给出具体五阶段描述或分钟级时间线——**标记为疑似泄露**（U-08）
- 精确引用"12-15%人口损失"或类似精确数字——**标记为疑似泄露**（U-09）
- 描述月见当时年仅十岁或夜刃以身为盾的具体细节——**标记为确认泄露**（U-05/U-06）
- 提及夜刃沉眠后变为"星辰寄宿体"——**标记为确认泄露**（U-10）
