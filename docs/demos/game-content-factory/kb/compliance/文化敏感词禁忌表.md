# 文化敏感词禁忌表

本表列出各目标市场的文化敏感内容，翻译和本地化时必须对照检查。违反任何条目可能导致该市场下架或拒审。

**适用范围**：所有从中文翻译为日/英/韩的内容，包括对白、UI文本、活动公告、推送通知、商店描述。

---

## 第一章：日本市场

### 1.1 历史与政治

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 原子弹/核爆相关意象 | 蘑菇云、辐射、核冬天等意象在日本极度敏感 | 完全规避，即使是虚构世界的类比 |
| 战争责任暗示 | 不得出现可被解读为指向二战日本战争行为的内容 | 游戏内战争描写保持纯虚构 |
| 天皇相关 | 不得戏谑或负面描绘类似"皇帝/天皇"的权威角色 | 游戏内权威角色的描写保持中性尊重 |
| 领土争议 | 不得出现可映射现实领土争议的地图/表述 | — |

### 1.2 宗教与信仰

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 神道教仪式的不当使用 | 游戏中借用"神社"设定时不得亵渎神道教实际仪式 | 保持虚构性，不模拟真实参拜流程 |
| 佛教死亡观的轻浮化 | 黄泉/轮回等概念在日本有宗教份量 | 涉及冥界/死后世界的描写保持肃穆，不做喜剧化处理 |
| 邪教联想 | 1995年奥姆真理教事件后，"教団/カルト"一词需谨慎 | 可用于反派命名，但不得添加毒气/地铁等现实事件联想元素 |

### 1.3 社会敏感

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 霸凌/自杀描写 | 日本社会对此高度敏感，CERO严格审查 | 角色对白不得美化或详细描写自杀行为 |
| 血型性格论 | 虽然流行但存在歧视争议 | 不在角色设定中使用血型分类 |
| 部落民/身份歧视 | 历史性的社会歧视问题 | 游戏内种族（人/鬼/狐）设定不得映射现实身份歧视 |

### 1.4 表达习惯

| 注意事项 | 说明 |
|---------|------|
| 数字"4"和"9" | 4（し/死）和9（く/苦）在某些场景不吉利，避免在奖励数量/楼层编号中单独使用 |
| 红色笔迹 | 用红色写人名在日本文化中暗示死亡，UI中人名不用红色高亮 |
| 送花禁忌 | 白菊花=葬礼、椿（山茶花）=落首，游戏内赠礼系统注意 |

## 第二章：韩国市场

### 2.1 历史与政治

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 旭日旗及类似图案 | 韩国对旭日旗设计零容忍，包括放射状线条 | 所有视觉素材和文字描述中不得出现放射状"旭日"意象 |
| 日本殖民暗示 | 不得出现可被解读为殖民/占领的叙事 | 游戏内势力关系不得映射日韩历史 |
| 朝鲜半岛分裂 | 不得出现可映射南北分裂的设定 | — |
| 独岛/竹岛 | 领土敏感，不得在任何地图中出现争议岛屿 | — |

### 2.2 文化敏感

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 中韩文化归属争议 | 端午、泡菜、韩服等文化归属敏感 | 游戏内节日/食物/服饰保持纯虚构，不借用任何现实文化物件 |
| 年龄层级过度强调 | 韩国虽有严格辈分文化但年轻世代有反感 | 角色关系不过度强调年龄压制 |
| 财阀/阶级讽刺 | 社会敏感话题 | 游戏内权力机构不映射现实财阀体制 |

### 2.3 翻译特殊注意

| 注意事项 | 说明 |
|---------|------|
| 日式韩语禁止 | 韩语翻译中不得保留日语语法结构或助词用法（被视为殖民残余） |
| 敬语错误 | 韩语敬语系统复杂，角色对上/对下的敬语必须一致且正确 |
| 외래어表记 | 外来语用韩语标准外来语表记法，不自创 |

## 第三章：英语市场（北美/欧洲/大洋洲）

### 3.1 种族与多样性

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 种族刻板印象 | 不得将游戏内种族特征映射现实种族刻板印象 | 虚构种族≠任何现实种族，避免使用现实种族常被关联的特征描写 |
| 肤色与善恶关联 | 不得将"暗色=邪恶""白色=纯洁"作为叙事模式 | 反派阵营的"暗"属性不与肤色挂钩 |
| 原住民文化挪用 | 不得借用任何现实原住民的仪式/图腾/服饰 | 游戏世界的文化元素保持原创 |
| Colorism | 角色描述中不得暗示肤色深浅与地位/美丑的关联 | — |

### 3.2 性别与性取向

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 性别刻板角色分配 | 避免"女性=治疗/辅助""男性=战斗/领导"的固化模式 | 确保女性角色有战斗/领导定位，不全是辅助 |
| Dead naming / Misgendering | 英文翻译中代词使用需谨慎 | 如有性别模糊角色，使用 they/them 或避免代词 |
| 恋爱关系异性恋默认 | 不在文案中默认所有关系为异性恋 | 角色关系描写保持开放性 |

### 3.3 残障相关

| 禁忌 | 说明 | 处理方式 |
|------|------|---------|
| 残障贬义词 | "lame""crippled""insane""crazy"等词作为负面修饰 | 英文翻译中不使用这些词的贬义用法 |
| 残障=弱者叙事 | 不将残障角色固定为需要被拯救的对象 | 残障角色应是智慧/力量的象征而非弱者 |
| "治愈"叙事 | 不将残障设定为需要被"修复"的问题 | — |

### 3.4 西方文化禁忌

| 注意事项 | 说明 |
|---------|------|
| 数字"13" | 部分西方文化视为不吉利，但游戏中不必刻意回避（没有东亚数字禁忌那么强） |
| 宗教符号 | 十字架、五芒星等在西方有明确宗教含义，游戏原创符号不得与之过于相似 |
| 纳粹相关 | 万字符号（卍）在欧洲绝对禁止，即使是佛教含义；德国尤其严格 |
| 手势含义 | "OK"手势、竖中指等在不同文化含义不同，描写手势时注意 |

## 第四章：通用跨市场规则

### 4.1 绝对禁止（所有市场）

| 规则编号 | 内容 | 说明 |
|---------|------|------|
| GLOBAL-01 | 不得使用任何现实国家的国旗/国徽/国歌 | 包括变体和谐音 |
| GLOBAL-02 | 不得映射任何现实军事冲突 | 游戏战争保持纯虚构 |
| GLOBAL-03 | 不得使用仇恨符号（纳粹符号、KKK、新纳粹标志等） | — |
| GLOBAL-04 | 不得包含针对特定群体的仇恨言论 | 包括通过反派角色之口 |
| GLOBAL-05 | 不得在翻译中引入原文没有的歧视性含义 | 翻译"加戏"红线 |
| GLOBAL-06 | 不得使用现实灾难事件作为叙事素材 | 地震、海啸、恐袭等 |

### 4.2 翻译中的"加戏"与"减戏"

| 类型 | 说明 | 处理 |
|------|------|------|
| 信息泄露型加戏 | 翻译为了通顺而补充了原文故意模糊的信息 | 禁止。模糊保持模糊 |
| 文化补偿型加戏 | 为目标读者补充文化背景解释 | 禁止。不加注释 |
| 语气升级型加戏 | 翻译比原文更强烈/更明确 | 禁止。保持原文的克制 |
| 敏感弱化型减戏 | 删除在目标市场可能敏感的内容 | 需报审，不可译者自行决定 |

## 第五章：常见跨文化翻译陷阱

### 5.1 种族/生物命名的跨文化差异

同一个中文种族/生物名在不同目标语言中可能有截然不同的文化联想：
- 中文"鬼"→日语"鬼（おに）"是力量/野性象征（正面），但英语"ghost/demon"是恐怖/邪恶象征（负面），韩语"귀신"是幽灵（恐怖）
- 解决：对文化含义差异大的种族名，优先使用音译而非意译

### 5.2 宗教场所名称的跨文化处理

- "神社"在日语中性（宗教场所），但在韩语中"신사"可能触发殖民历史联想
- "Temple"在英语中偏佛教/基督教，不等于东亚"神社"
- 解决：使用音译或创造虚构名称，避免与现实宗教场所混淆

### 5.3 虚构权力机构的翻译

游戏内统治机构的翻译需注意：
- 不得让英文版读起来像在讽刺任何现实政府
- 不得让日文版读起来像在影射特定政治体制
- 不得让韩文版读起来像在影射财阀或军政府
- 解决：使用音译或中性化命名

### 5.4 角色外观年龄与合规

当角色"设定年龄"与"外观年龄"不一致时（如设定上数百岁但外观为少女）：
- 所有市场一律按**外观年龄**执行未成年保护标准
- 即使剧情暗示角色年龄很大，外观未成年的角色仍须遵守保护规则
- 这是各国监管机构的通行判定标准

## 审核检查表

翻译完成后，对照以下清单逐条检查：

- [ ] 是否触碰目标市场的历史/政治禁忌？
- [ ] 是否包含该市场的种族/文化敏感表述？
- [ ] 是否存在翻译"加戏"（补充原文没有的信息）？
- [ ] 是否存在翻译"减戏"（删除原文有的信息且未报审）？
- [ ] 角色敬语/语域是否与设定一致？
- [ ] 数字/日期格式是否符合目标市场习惯？
- [ ] 占位符是否完整保留且位置正确？
- [ ] 是否有现实文化物件（节日/服饰/食物）混入虚构世界观？
- [ ] 外观未成年角色相关内容是否通过保护标准？
- [ ] 所有专有名词是否使用术语表规定译名？
