# 合规审核细则

本文档定义游戏对外输出内容须遵守的法律法规和平台规则。按地区分章节，适用于所有目标市场。本文档与具体游戏项目无关，由法务合规团队统一维护。

**适用范围**：游戏内对白、活动公告、社区回复、push 推送、版本更新说明、社交媒体帖文、商店页面描述。

**审核原则**：以最严格市场的标准为基准，确保一份内容通过所有目标市场审核。当各市场标准冲突时，取交集。

---

## 第一章：中国大陆

### 1.1 广告法绝对化用语（红线）

依据：《中华人民共和国广告法》第九条第三项

**禁用词清单（触发即打回）**：

| 类别 | 禁用词 |
|------|--------|
| "最"系列 | 最好、最强、最佳、最高、最低、最优、最大、最新、最先进、最受欢迎、最流行、最便宜、最具 |
| "第一"系列 | 第一、NO.1、TOP.1、排名第一、销量第一、全网第一、全球第一 |
| "唯一"系列 | 唯一、独一无二、独家、绝无仅有、首个、首款、首家、首选 |
| 极限词 | 顶级、极致、永久、万能、无敌、绝对、空前绝后、史无前例、国家级、世界级 |
| 权威暗示 | 国家推荐、官方认证、专家推荐（除非有真实授权文件） |

**例外**：游戏内世界观叙事中使用"最强""第一"描述虚构角色/事物不受广告法约束，但对外宣传文案（公告、推送、社区帖、商店描述）严格禁止。

**正面示例**：
- "新活动开启——玩家，属于你的奖励在等待。"
- "本次活动奖励丰厚，不容错过。"

**反面示例**：
- ~~"史上最强活动！独家奖励！错过就没了！"~~
- ~~"全网第一RPG"~~
- ~~"最后机会！限时抢购！"~~

### 1.2 付费诱导（红线）

依据：《网络游戏管理办法（草案征求意见稿）》第十七条、第十八条、第二十七条

**禁止的表述模式**：

| 禁止模式 | 说明 | 示例（反面） |
|---------|------|-------------|
| 限时恐慌 | 制造"不买就亏"的紧迫感 | ~~"仅剩最后3小时！""限时抢购！""错过再等一年！"~~ |
| 首充诱导 | 暗示首次付费有特殊价值 | ~~"首充双倍！""新手必买礼包"~~ |
| 连续充值暗示 | 鼓励持续消费 | ~~"连续签到7天送SSR""充值满X天解锁"~~ |
| 概率模糊 | 抽卡/随机奖励不公示概率 | ~~"超稀有掉落！""惊喜宝箱等你开"~~（未附概率） |
| 比较施压 | 暗示不付费就落后 | ~~"90%的玩家已经拥有了""你还在用初始装备？"~~ |

**合规表述范式**：
- 活动公告客观陈述奖励内容和获取方式
- 使用叙事包装而非营销话术："星辰结晶将在祭典期间降临"而非"限时打折快来买"
- 抽卡活动必须附概率公示链接

### 1.3 未成年人保护

依据：《未成年人网络保护条例》（2024年1月1日施行）、《关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》（830新规）

**内容红线**：

| 规则编号 | 规则 | 说明 |
|---------|------|------|
| CN-M01 | 禁止对外观未成年的角色进行性暗示描写 | 包括暧昧对白、身体特写描述、恋爱暗示 |
| CN-M02 | 禁止美化未成年角色的暴力行为 | 可以有冒险感但不可有残忍感 |
| CN-M03 | 禁止在面向未成年人的内容中出现随机抽取服务 | 活动文案不得变相推广抽卡 |
| CN-M04 | 禁止制造"不玩就落后"的焦虑 | 包括排行榜施压、每日登录奖励暗示 |

**注意**：外观年龄低于18岁的角色（无论设定上的实际年龄），其所有对白和宣传素材需格外注意 CN-M01。

---

### 1.4 政治与宗教

依据：《网络出版服务管理规定》第二十四条

**绝对禁止**：
- 任何可映射现实政治事件/人物的内容
- 任何现实宗教经典/教义的直接引用或改编
- 任何可被解读为国家/民族/种族歧视的表述
- 使用现实国旗、国徽、军徽等符号或谐音变体
- 歪曲历史事实的内容

**注意**：游戏内虚构的治理机构/政治体制不得被写成可映射任何现实国家政治体制的形式。

---

### 1.5 暴力分级

依据：版号审核实践标准

| 允许 | 需谨慎 | 禁止 |
|------|--------|------|
| 战斗动作描写（无血腥细节） | 角色受伤描写（点到为止） | 肢解、内脏暴露、酷刑细节 |
| "击败""消灭"等抽象表述 | 流血暗示（"鲜血滴落"） | 对尸体的侮辱性描写 |
| 战斗中的紧张感 | 死亡暗示（需模糊处理） | 以杀戮为乐趣的描写 |

**通用指导**：战斗台词保持"凌厉感"而非"血腥感"。角色对白可以冷酷但不可残忍。

## 第二章：日本（CERO）

### 2.1 CERO 分级标准

常见目标分级：**CERO B（12岁以上）**

维持B级需遵守的内容限制：

| 维度 | B级允许范围 | 超出即升级为C/D |
|------|-----------|--------------|
| 暴力 | 轻微战斗描写、无真实血液 | 真实血液飞溅、肢解 |
| 性表现 | 轻微暗示（对话中的间接暗示） | 裸露、直接性描写 |
| 恐怖 | 轻微阴森氛围 | 极度恐怖、尸体特写 |
| 犯罪 | 反派行为的间接描述 | 详细犯罪手法教学 |
| 饮酒/烟草 | 场景中存在（非鼓励） | 鼓励未成年角色饮酒 |

**特别注意**：
- CERO 对性内容比暴力内容审查更严格
- 角色服装描写避免"性挑逗"暗示
- 战斗场景避免"人体切断"描写

---

### 2.2 日本特有合规要点

| 规则编号 | 规则 | 说明 |
|---------|------|------|
| JP-01 | 概率表示义务 | 抽卡活动必须明示各奖品获得概率（Apple/Google日本商店要求） |
| JP-02 | 景品表示法 | 宣传文案不得做出超出实际的品质/价值表示（"有利误认表示"禁止） |
| JP-03 | 特定商取引法 | 付费内容必须明示贩卖者信息 |
| JP-04 | 未成年消费保护 | 民法上未成年人的消费取消权广泛保护 |

## 第三章：韩国（GRAC）

### 3.1 GRAC 分级标准

常见目标分级：**12岁以上**

| 维度 | 12级允许范围 | 备注 |
|------|-----------|------|
| 暴力 | 非写实战斗、无血液 | 韩国标准比日本更保守 |
| 性表现 | 仅极轻微暗示 | 比同级CERO更严格 |
| 恐怖 | 轻微悬疑氛围 | — |
| 语言 | 避免脏话和侮辱性用语 | — |
| 赌博/射幸 | 需概率公示 | 2024年3月起法定义务 |

### 3.2 概率公示法（2024年3月施行）

依据：韩国《游戏产业振兴法》第33条修正案

**强制要求**：
- 所有随机抽取（抽卡/宝箱/掉落）必须在游戏 UI 内明确公示概率
- 概率信息必须在购买页面直接可见（不能藏在帮助/设置中）
- 虚假公示将面临巨额罚款（参考：Nexon 2024年因概率欺骗被罚116亿韩元）

**活动文案合规要求**：
- 提及抽卡/随机奖励的文案必须附注"详细概率请查看游戏内公示"
- 不得使用"必得""保底"等表述除非机制确实如此

### 3.3 未成年人消费限制

- 未成年人月消费上限 70,000 韩元（约 370 元人民币）
- 19岁以下不得购买成人限定内容
- 深夜（0:00-6:00）禁止16岁以下用户游玩（shutdown制度虽已废除但平台仍有自律规范）

## 第四章：欧洲（PEGI）

### 4.1 PEGI 分级标准

常见目标分级：**PEGI 12**

| 内容描述符 | PEGI 12 允许范围 | 触发升级的内容 |
|-----------|----------------|--------------|
| Violence | 对幻想角色的非写实暴力 | 对人类角色的写实暴力→PEGI 16 |
| Bad Language | 轻度不雅词汇 | 性脏话→PEGI 16 |
| Fear | 可能惊吓幼儿的场景 | 持续恐怖氛围→PEGI 16 |
| Discrimination | 绝对禁止（任何级别） | 任何歧视内容直接拒审 |
| Sex | 姿态暗示 | 裸露/性行为→PEGI 16/18 |
| Gambling | 幻想化赌博元素 | 真实赌场模拟→PEGI 18 |
| In-Game Purchases | 需标注描述符 | 含随机付费物品→PEGI 16（2025新规） |

### 4.2 PEGI 2025 互动风险新规

**关键变化**（2025年6月生效）：
- 含抽卡/随机付费物品的游戏最低 PEGI 16
- 含限时/限量促销的游戏最低 PEGI 12
- 含 NFT/区块链机制的游戏 PEGI 18
- 含"每日登录奖励"等参与设计机制的游戏最低 PEGI 7（需新描述符）

**对文案的影响**：
- 欧洲市场的活动文案不得包含"限时""仅剩X份"等表述（触发更高分级风险）
- 社区帖文中提及付费内容时需谨慎

### 4.3 EU 数字公平法（预期 2026-2027）

欧洲议会 IMCO 委员会已投票要求禁止面向未成年人的抽卡/战利品箱。虽尚未立法，但内容应提前规避：
- 面向欧洲市场的文案中不得将抽卡包装为"惊喜""冒险"等吸引未成年人的表述
- 避免在社交媒体上展示抽卡"欧皇"结果以制造射幸心理

## 第五章：北美（ESRB）

### 5.1 ESRB 分级标准

常见目标分级：**T（Teen，13岁以上）**

| 内容描述符 | T级允许范围 | 触发M级的内容 |
|-----------|-----------|------------|
| Violence | 战斗暴力、轻微血液 | 写实血腥、肢解、酷刑 |
| Blood | 少量血液表现 | 大量血液和肢体损毁（Blood and Gore） |
| Language | 轻度到中度脏话 | 频繁的强烈脏话 |
| Suggestive Themes | 轻度性暗示 | 明确性内容/裸露 |
| Simulated Gambling | 模拟赌博元素 | — |
| In-Game Purchases | 需标注（含随机物品需额外标注） | — |

### 5.2 ESRB 互动元素标注

以下互动元素需在文案/商店页面标明：
- **In-Game Purchases**：游戏内可用真实货币购买内容
- **In-Game Purchases (Includes Random Items)**：含随机付费物品
- **Users Interact**：玩家之间可交互
- **Shares Location**：分享位置信息

## 第六章：通用合规规则

### 6.1 隐私与数据保护

| 规则编号 | 规则 | 适用市场 |
|---------|------|---------|
| PRI-01 | 对外内容中不得暴露任何真实用户数据（ID、邮箱、IP等） | 全球 |
| PRI-02 | 社区回复中不得引用玩家私信内容 | 全球 |
| PRI-03 | 活动文案不得暗示平台持有/使用玩家行为数据 | EU（GDPR）|
| PRI-04 | 不得在面向未成年人的内容中收集/展示个人信息 | 全球 |

### 6.2 反歧视

| 规则编号 | 规则 | 说明 |
|---------|------|------|
| DIS-01 | 禁止基于种族、民族、性别、性取向、宗教、残疾的歧视性表述 | 包括隐晦的刻板印象 |
| DIS-02 | 游戏内势力冲突不得映射现实种族/民族矛盾 | 夜见世界的人鬼冲突是纯虚构 |
| DIS-03 | NPC 对白不得使用歧视性侮辱（即使是反派角色） | 反派可以邪恶但不可歧视 |
| DIS-04 | 翻译时注意目标语言中的文化敏感词 | 不同文化对同一词汇的敏感度不同 |

### 6.3 虚假宣传

| 规则编号 | 规则 | 说明 |
|---------|------|------|
| AD-01 | 文案内容必须与实际游戏体验一致 | 不得展示游戏中不存在的功能/画面 |
| AD-02 | 奖励描述必须准确 | "星辰结晶×100"必须确实给100个 |
| AD-03 | 活动时间必须准确标注 | 含起止时间和时区 |
| AD-04 | 不得使用虚假玩家评价/数据 | "百万玩家参与"必须有数据支撑 |

### 6.4 知识产权

| 规则编号 | 规则 | 说明 |
|---------|------|------|
| IP-01 | 不得使用任何第三方品牌名称、商标、角色形象 | 包括隐晦的模仿 |
| IP-02 | 不得使用受版权保护的音乐/诗歌/文学作品片段 | 古籍引用限于夜见世界原创 |
| IP-03 | 联动活动须确认授权后方可发布文案 | — |

## 第七章：平台特殊规则

### 7.1 Apple App Store

- 含抽卡的游戏须在购买前明示概率
- 订阅类内容须清晰标注价格和周期
- 17+ 评级的游戏不得在面向未成年人的推广中出现
- 日本地区：合规民法的未成年消费取消权

### 7.2 Google Play

- 遵循 IARC 统一评级系统
- 韩国地区：须遵守 GRAC 评级和概率公示
- 付费内容须明确标注"包含应用内购买"
- 不得在推送通知中使用诱导性付费话术

### 7.3 主机平台（PlayStation / Nintendo Switch）

- 各平台有独立内容审查流程
- Nintendo 对性暗示内容审查比 Sony 更严格
- 主机版本内容标准以 CERO/PEGI/ESRB 对应评级为准

## 第八章：合规审核检查表

审核任何对外内容时，按以下顺序检查：

### 第一步：硬红线速查

- [ ] 是否包含广告法绝对化用语？
- [ ] 是否包含付费诱导话术？
- [ ] 是否涉及未成年角色的不当描写？
- [ ] 是否包含现实政治/宗教/品牌引用？
- [ ] 是否暴露真实用户数据？
- [ ] 是否包含歧视性内容？

### 第二步：分级合规

- [ ] 暴力描写是否超出 T/B/12 级标准？
- [ ] 性暗示是否超出 T/B/12 级标准？
- [ ] 语言是否超出目标分级允许范围？

### 第三步：商业合规

- [ ] 付费内容是否如实描述？
- [ ] 随机抽取是否附概率公示？
- [ ] 活动时间是否准确标注？
- [ ] 奖励承诺是否可兑现？

### 第四步：文化本地化

- [ ] 内容在目标市场是否有文化敏感问题？
- [ ] 翻译是否引入了原文没有的敏感含义？
- [ ] 幽默/谐音/双关是否在某些语言中变成冒犯？

## 附录C：常见误判案例

### 案例一：游戏内叙事 vs 对外宣传

**误判**："对白中角色说'我是最强的'，这违反广告法？"
**正确判断**：游戏内虚构角色的台词不受广告法约束。广告法约束的是对外的商业宣传文案。但如果把这句话用在商店页面描述中作为卖点，则可能构成问题。

### 案例二：活动文案的"稀有"描述

**误判**："文案写了'超稀有道具'，这算诱导？"
**正确判断**：描述道具的稀有度本身不违规（"稀有""传说""史诗"是游戏分级系统的常规命名）。违规的是"超稀有=你必须花钱抽"的暗示链条。如果后面附了获取方式和概率公示，则合规。

### 案例三：限时活动的表述

**误判**："所有限时活动都不能写了？"
**正确判断**：限时活动本身合法。违规的是利用时间制造恐慌（"最后3小时！""错过就没了！"）。合规写法是客观陈述时间："活动时间：5月1日 - 5月15日"。

### 案例四：暴力描写的边界

**误判**："战斗台词里角色说'斩'，是不是暴力？"
**正确判断**：单字的战斗动作描述在所有市场的目标分级内都是允许的。问题出在"描写暴力的结果"——"斩"是合规的，"鲜血喷涌、头颅滚落"是不合规的。
