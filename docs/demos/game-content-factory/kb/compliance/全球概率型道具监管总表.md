# 全球概率型道具监管总表

> 维护团队：法务合规组  
> 适用范围：所有包含概率型道具的游戏产品  
> 最后更新：2026-05-17  

---

## 1. 概述

"概率型道具"（Probability-Based Items）是指玩家通过支付货币（真实或虚拟）获取随机结果的机制。常见形态包括：

- **抽卡/扭蛋（Gacha）**：单次或连抽，按概率池出货
- **战利品箱（Loot Box）**：购买后随机开启获得道具
- **卡包（Card Pack）**：集换式卡牌的随机组合包
- **转盘/轮盘（Prize Wheel）**：视觉化的随机抽奖
- **盲盒（Mystery Box）**：付费后随机获得虚拟或实体物品
- **保底机制（Pity System）**：达到一定次数后保证产出

各国对此类机制的监管立场从"完全禁止"到"行业自律"不等。本文档提供跨地区合规对照，供 AI 审核系统和内容团队参考。

## 3. 中国

### 法规依据

- 文化部《网络游戏管理暂行办法》配套通知（2017年第16号文）
- 《未成年人保护法》2021年修订版
- 国家新闻出版署"防止未成年人沉迷网络游戏"通知（2021年8月）

### 核心要求

1. **概率公示**：所有虚拟抽取服务必须在显著位置公示各档位获取概率
2. **禁止诱导过度消费**：不得设计诱导玩家不理性消费的机制
3. **未成年人禁用**：未成年人不得使用随机抽取付费服务
4. **替代购买途径**：必须提供直接购买（非随机）方式获取同等道具
5. **次数限制公示**：如有保底机制，必须明确告知所需次数

### 执行情况

- 表面合规率极高，几乎所有上线产品均标注了概率
- 实际问题：概率公示常藏在多级菜单深处、字体极小、入口不明显
- 监管机构不定期抽查，通常在舆情事件后集中执法

### 注意事项

- "替代购买途径"不等于"高价直购"——价格必须合理，不得变相逼迫抽取
- 概率公示必须在抽取界面可直接触达，不允许跳转外部网页

## 4. 韩国

### 法规依据

- 游戏产业振兴法（게임산업진흥에 관한 법률）第33条，2024年3月修订生效

### 核心要求

1. **游戏内 UI 概率公示**：必须在游戏界面内显示，不得仅在外部网站公布
2. **分级概率**：每个可获取道具的单独概率必须列出
3. **未成年人消费上限**：月消费不得超过 ₩70,000（约 $52 USD）
4. **变更通知**：概率调整须提前公告并保留历史记录

### 执法案例

- 2024年：Nexon 因概率操控被罚 ₩11.6B（约 $8.7M USD），为韩国游戏业最高罚款
- 修法后合规率达 84.4%，远超此前自律时代的水平

### 注意事项

- 韩国用户对概率透明度极为敏感，社区舆论可迅速升级为监管行动
- "组合概率"（合成/升级类）同样适用公示义务

## 5. 日本

### 法规依据

- 不正当景品类及不正当表示防止法（景表法）——消费者厅2012年解释
- JOGA（日本オンラインゲーム協会）自律规范
- CERO 评级体系（自律性质）

### 核心要求

1. **Complete Gacha 禁止**（2012年起）：不得设计"集齐多个随机道具组合兑换稀有物品"的机制
2. **概率公示**：JOGA 自律指南要求会员企业公示，但非法定强制
3. **上限建议**：JOGA 建议单次抽取上限 ₩50,000（约 ¥5,000），但无强制力
4. **表示真实性**：概率标注必须真实，虚假标注适用景表法处罚

### 执行情况

- 自律为主，政府介入门槛高
- 2012年コンプガチャ禁止令起因于社会事件，此后行业高度自觉回避类似设计
- 非 JOGA 会员企业不受自律规范约束

### 注意事项

- Complete Gacha 的定义较宽——任何"收集随机零件→组合成稀有品"的设计均触发
- 日本市场对 gacha 接受度高，但对欺诈性概率标注零容忍

## 6. 欧洲

### 比利时

- 2018年赌博委员会（Kansspelcommissie）裁定：付费开箱 = 赌博
- 需要赌博牌照方可运营，游戏发行商普遍选择移除功能而非申请牌照
- **关键数据**：尽管"禁令"存在，研究显示 82% 的热门游戏仍包含某种形式的 loot box（执法力度有限）
- 典型案例：Pokémon Unite 因合规成本从比利时/荷兰下架

### 荷兰

- 2018年赌博局（Kansspelautoriteit）对含可交易随机物品的游戏执法
- 2024年法院判决部分推翻此前立场，执行力减弱
- **关键数据**：执法期间 2/3 的游戏未提供概率公示
- 目前处于法律不确定状态，建议按"需要公示"标准执行

### PEGI 2025 新规

- 含"付费随机道具"（Paid Random Items）的游戏自动获得最低 PEGI 16 评级
- 购买界面必须展示 "Paid Random Items" 标识
- 适用于所有 PEGI 评级地区（覆盖欧洲及部分中东/亚太市场）

### EU Digital Fairness Act

- 预计 2026-2027 年间出台
- 草案方向：将 loot box 纳入数字消费者保护框架
- 可能要求：概率公示、消费上限、未成年人保护、冷静期机制
- 建议：提前按最严标准（比利时模式）设计合规方案

## 7. 北美

### 美国

**现状：无联邦专项立法，依赖行业自律 + FTC 执法**

- **ESRB 标签**（2020年起）：包含随机付费物品的游戏标注 "In-Game Purchases (Includes Random Items)"
- **FTC 执法**：Epic Games 2022年被罚 $520M（含 Fortnite 暗黑模式、未成年人消费等）
- **集体诉讼**：Valve（Steam 市场随机物品交易）、EA（FIFA Ultimate Team）等面临诉讼
- **州级提案**：加州、夏威夷、明尼苏达等州提出 loot box 监管法案，均未通过

### 加拿大

- 无专项立法
- 各省消费者保护法可能适用
- 行业参照 ESRB 标准执行

### 注意事项

- 美国法律环境变化快，集体诉讼风险高
- FTC 有权以"不公平或欺骗性行为"起诉，不需要专项立法
- 加州 CCPA/CPRA 下的儿童数据保护间接影响未成年人 gacha 消费追踪

## 8. 其他地区

### 澳大利亚

- 参议院2023年发布调查报告，建议将 loot box 纳入消费者保护法
- ACCC（竞争与消费者委员会）可依据现行法律对误导性概率表述执法
- 预计2025-2026年出台具体立法

### 西班牙

- 2024年通过《数字环境中未成年人保护法》
- 建立专门的概率型道具监管框架
- 禁止向未成年人销售/推广随机付费道具
- 罚款上限 €1M

### 巴西

- 消费者保护法（CDC）要求产品信息透明
- 正在讨论是否将虚拟随机道具纳入博彩法管辖
- PROCON（消费者保护机构）已对多起游戏投诉立案
- 建议：对巴西市场产品主动提供概率公示

## 9. 文案合规检查要点

AI 审核系统和内容创作团队在涉及概率型道具时，必须遵守以下规则：

### 必须做到

| 编号 | 规则 | 说明 |
|------|------|------|
| P-01 | 概率公示链接 | 任何提及抽取/开箱的文案必须包含或链接到概率公示页面 |
| P-02 | 真实性表述 | 概率描述必须与实际配置完全一致，不得使用模糊修饰 |
| P-03 | 保底说明 | 如有保底机制，必须明确说明所需次数和保底内容 |
| P-04 | 费用透明 | 必须明确标注单次抽取所需的真实货币等价金额 |
| P-05 | 未成年人隔离 | 面向未成年人的推送/广告中不得出现 gacha 推广内容 |

### 绝对禁止

| 编号 | 禁止行为 | 原因 |
|------|---------|------|
| X-01 | 无概率公示的抽卡推广 | 违反中国、韩国强制规定 |
| X-02 | 使用"保证获得"但实际为概率机制 | 构成虚假宣传，全球违法 |
| X-03 | 向未成年人推广 gacha | 违反中国、韩国、西班牙、PEGI 规定 |
| X-04 | "限时""仅剩X份"制造虚假紧迫感 | 多国认定为诱导过度消费 |
| X-05 | 暗示抽取结果可影响（"手气""运气"） | 构成对随机性的误导 |
| X-06 | 隐藏概率变动信息 | 韩国要求变更须公告，其他地区视为欺诈 |
| X-07 | Complete Gacha 设计 | 日本明确禁止 |
| X-08 | 展示他人抽取稀有结果诱导跟风 | 多国视为诱导性设计 |

### 审核流程建议

1. 文案提交 → AI 初审（本文档规则匹配）→ 人工复核
2. 涉及新市场上线时，须按该地区最新法规更新审核规则
3. 概率调整公告文案须经法务审批后发布
4. 每季度对照本表更新各地区最新动态
