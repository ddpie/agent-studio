## 地理特征

### 整体布局

樱花神社坐落于中央灵脉带的山腰处，海拔约800步高度。从山脚至正殿需攀登365级石阶，每一级石阶代表一年中的一天，据传由初代巫女以灵力逐级凿刻而成。石阶两侧每隔十步立有一盏星萤石灯笼，散发淡蓝冷光，即便在最深的夜晚也不会熄灭。

### 核心区域

**正殿**：三进式木质建筑群，屋顶覆有黑色瓦片，瓦缝间生长着极细的灵草。正殿供奉的并非具体神像，而是一面直径两步的圆形铜镜，镜面永远映照着满月之景。

**月见池**：位于正殿后方，直径约五十步的圆形水池。池水清澈见底，但无论何时俯瞰，水面都映照着一轮满月——这是月见一族以"映月术"持续维持的结果。月见池底铺满白色细沙，偶尔可见银色锦鲤游动。

**风铃庭**：正殿西侧的开放式庭院，悬挂着数百只形态各异的风铃。风铃材质包括青铜、白银、水晶和灵木，在不同风向下会奏出不同旋律。千早在此进行日常冥想与修炼。

**永恒樱花林**：覆盖神社周围约三百步半径范围的樱花树群落。这些樱花处于永恒绽放与飘落的循环中——花瓣落下的瞬间即化为灵力微粒回溯至枝头，形成无尽的飘落之景。

**北侧竹林屏障**：神社北面是一片极为浓密的翠竹林，竹竿粗逾一抱，竹叶间弥漫着浓重迷雾。竹林深处存在一条小径，在当前版本（3.1）中被不可穿透的迷雾完全封锁，玩家无法进入。

### 自然环境

- 气候：常年春季，温度恒定于15-20度之间
- 光照：永恒黄昏偏暮色的柔和光线，天空呈现淡紫与橙色渐变
- 水系：月见池地下连接灵脉泉眼，是整个中央灵脉带的灵力枢纽

## 氛围与美学

### 视觉

主色调为淡粉（樱花）、深靛（夜空）、淡蓝（星萤石光芒）三色交织。建筑木材呈现深褐色自然老化纹理，金属饰件以青铜和暗银为主。永恒飘落的樱花瓣在淡蓝灯光映照下呈现半透明质感，仿佛时间在此处被温柔地冻结。

月见池的月光映照为场景提供了核心光源之一，银白月光与淡蓝星萤石光形成冷色双层照明，使整个神社笼罩在清冷而神圣的氛围中。

### 听觉

- 基底音：樱花瓣飘落时的极轻微簌簌声（持续循环）
- 律动音：风铃庭传来的不规则铃声，音色清冽
- 环境音：竹林风声、池水微波、偶尔传来的木鱼声
- 缺失音：无鸟鸣、无虫声——灵脉圣域中普通生物不入

### 体感

玩家在神社范围内会感受到一种"灵压"——表现为轻微的耳鸣和微凉的皮肤触感。这是灵脉能量的外在表现。接近月见池时体感变为"温润"，接近北侧竹林时则变为"压迫"。

## 历史沿革

| 时期 | 事件 |
|------|------|
| 约800年前 | 初代巫女于灵脉枢纽处建立简易祭坛 |
| 约700年前 | 月见一族定居此地，建造正殿与月见池 |
| 约500年前 | 千早先祖加入，风铃庭建成 |
| 约300年前 | 星陨事件发生，神社受到冲击但未被摧毁。北侧竹林在事件后异常生长加密 |
| 约200年前 | 永恒樱花现象开始出现（原因不明，部分学者认为与灵脉紊乱有关） |
| 约100年前 | 365级石阶改造完成，星萤石灯笼安装 |
| 当前（3.1版本） | 月见担任现任守护者，千早为见习巫女。北侧竹林迷雾加重 |

## 玩家可做的事

1. **主线剧情推进**：与月见对话触发守护者系列主线
2. **灵力修炼**：在月见池边进行灵力冥想（buff获取）
3. **风铃制作**：跟随铃师傅学习，制作功能性风铃道具
4. **石阶挑战**：限时攀登365级石阶（速度挑战，排行榜）
5. **隐藏任务**：追踪灵猫落叶、与白霜对话（需满月时段）
6. **材料采集**：各类灵性材料的日常采集
7. **观景休息**：在风铃庭休息可获得"宁静"状态（24小时经验加成5%）
8. **摄影取景**：樱花+月见池为热门截图地点

### 审核示例

**通过的对白**：
- "樱花又在飘落了呢...每一片都像是在跳舞。"
- "月见大人正在月见池边冥想，请不要打扰她。"
- "北边的竹林迷雾好浓，完全看不清里面有什么。"

**不通过的对白**：
- "听说竹林深处通往一片星光闪耀的森林。"（违反SS-001）
- "那个旅行商人...他的眼睛和月见大人好像呢。"（违反SS-002）
- "月见池底下好像有什么东西在发光..."（违反SS-004）
- "月见大人看起来很年轻，但据说她已经守护这里三百年了。"（违反SS-006）
