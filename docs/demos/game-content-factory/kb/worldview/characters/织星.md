## 外观描述

（以下描述基于回忆场景和残影出现时的形象）

身高约 168cm，体态端庄温润，是"成熟女性的安定感"。动作总是从容优雅，即便在危急时刻也不慌乱——不是冷漠，是已经做好了所有准备。

**发型与发色**：银白色长发比月见更亮更纯粹，编成精致高髻以白金丝线固定。发髻形状如盛开的花苞。散落时长度及膝。发色在觉醒星辰之力后由原本的黑色完全转变为银白。

**面容**：轮廓柔和中带骨感，眉目修长，面部比月见更为成熟端丽。最显著的是一双金色眼睛——不是天生，是长期运用星辰之力后虹膜色素改变。金瞳温暖如烛火，目光注视任何人时都让人感到"被接纳"。嘴角常带微笑，但仔细看笑意不达眼底——那里有先知者的悲伤。

**服饰**：白色巫女长袍外加银线绣花的正式羽织，是巫女长正装。腰间系金色丝绳，坠着完整的星辰石（非碎片）。头上别白玉梅花簪。全身色调白金为主——如月光凝结的形态。

**残影状态**：当以记忆残影出现时，形象会有轻微失真——边缘微微模糊发光，声音像隔着水面传来，面容中某些细节（如眼中倒影）无法清晰呈现，因为是不完整的记忆碎片。

**特殊标记**：双手手背布满极细银色纹路——长期直接操作星辰之力的痕迹。右肩有一处月牙形疤痕（年轻时保护月见受伤留下）。

## 性格深度剖析

### 1. 慈悲与果决的统一

核心矛盾在于"无限温柔"与"绝对果决"的共存。对世间万物怀有深切悲悯，但在必须抉择时从不犹豫。自我牺牲的决定不是瞬间冲动——是深思熟虑后"这是最优解"的理性结论，然后带着微笑去执行。

### 2. 责任承担者

天生的"母亲型"人格，不是学来的而是本能。永远第一个站出来承担责任、吸收伤害、做那个"说没关系的人"。这种特质既是美德也是缺陷——她习惯性地将所有重担压在自己身上，从不求助，认为"让他人操心就是我的失败"。

### 3. 先知的孤独

觉醒星辰之力后获得一定程度的预知能力（不精确但方向性准确）。当你知道某些事"终将发生"却无法改变时，陪伴变成了一种折磨——明知道月见会失去自己、夜刃会陷入沉眠，依然选择在此刻温柔地陪伴。每一次微笑都是"在离别前多给一点温暖"。

### 4. 对月见的深爱

超越姐妹、超越养母的存在。月见是她"在这个世界上最重要的事"。所有选择的最终优先级都是"月见能平安活下去"。施加记忆封缄不是残忍，是"如果她记得一切会崩溃，先让她忘记，将来有人能帮她承受时再想起"的深远考量。

### 5. 被遮蔽的悔恨

唯一的遗憾是"没能教会月见如何在没有我的情况下生活"。预知能力告诉她自己会消失，但始终没找到好的方式告别。最终选择记忆封缄——这本身就是某种逃避。

### 6. 对夜刃的信任与托付

认为夜刃是"唯一可以在我之后守护月见的人"。在星陨事件中做出封印安排时，将夜刃的沉眠设计为"可苏醒"而非"永远封印"——这是她的最后托付（4.0 公开）。

## 背景故事

### 早年与成为巫女长（约 350-310 年前）【机密：4.0 公开完整版】

樱花神社普通巫女出身，因才能突出逐步晋升。二十岁左右在一次星辰之力失控事件中挺身而出成功封印，获得前任巫女长认可。二十五岁正式成为巫女长，是历代最年轻。

### 收养月见（约 310 年前）【机密：4.0 公开完整版，3.2 暗示关系】

月见母亲（樱花之神第七代神使）怀孕时来到神社寻求庇护。织星作为巫女长接纳了她并保守秘密。神使分娩后消亡，织星接过婴儿月见。对外称"捡到的弃婴，收为师妹抚养"，实际以养母的方式全心照料。

为保护月见的半神血统不被发现，织星亲自设计了一套"融入人类"的教育方案——教月见如何控制力量外泄、如何模拟正常的衰老节奏（每三十到五十年"离开再回来"的策略）。

### 星陨事件（300 年前）【部分公开：事件存在已知，织星牺牲已知，细节逐版本揭示】

星辰碎片坠落时释放的能量足以毁灭半径数百里的所有生灵。织星以巫女长的全部力量加上自身生命力作为封印媒介，将碎片的破坏力压缩封入极小范围。封印过程中：

1. 夜刃冲入危险区保护月见，承受部分碎片冲击
2. 织星顺势将封印扩展，将夜刃和碎片一同"暂停"——这不是意外，是她在瞬间做出的计算：与其让夜刃死亡，不如让他沉眠等待碎片被身体完全吸收的那天
3. 封印完成后织星的肉体开始消散，最后一刻对月见施加记忆封缄
4. 消散前最后的话是对月见说的——具体内容 4.0 公开

### 消散后的存在形式

织星并非完全消失。她的意识碎片嵌入了封印结构中，以极微弱的形式存续。这解释了：
- 月见偶尔在梦中听到的"声音"
- 神社某些角落突然出现又消失的微光
- 残影形式的出现（特定条件触发）

## 说话风格与禁忌

### 语言特征（回忆/残影中）

1. **全部过去式**：因为已经不在了。"那时候……""曾经……""在那个时候，我——"
2. **温暖但悲伤**：语气永远温柔，像母亲哄孩子入睡。但字里行间有无法消散的哀愁
3. **不知道"现在"**：残影不了解当前世界状况。"现在……是什么季节？樱花开了吗？"
4. **温柔称呼**：称月见为"小月"或"月见"（从不用全名）。称夜刃为"那个孩子"（即使夜刃比她高大）
5. **被遮蔽的部分**：某些关键信息说到一半会模糊——残影的限制。"我当时……那个……（模糊）……对不起，想不起来了"
6. **不说再见**：从不使用"再见""永别"等词。用"下次见"或"等樱花再开的时候"
7. **对被遮蔽对象的特殊称呼**：提到月见的母亲时只说"那个人"，提到樱花之神时说"那位大人"

### 正面范例

- "……小月。你今天，看起来很精神呢。"
- "那时候的天空……很美。星星好像要落下来一样——啊，后来确实落下来了呢。"
- "没关系的。无论发生什么，都——没关系的。"
- "那个孩子……他还好吗？……不，你不用回答。"
- "我有时候会想……如果那天我选了另一条路……不，这样想没有意义。"

### 反面范例（绝对不能出现）

- "我已经死了，所以你们要坚强地活下去！"（不会如此直白谈论自己的死）
- "月见，你必须记住所有事情！"（她主动封缄了月见的记忆）
- "我后悔牺牲了自己。"（不后悔选择本身，只遗憾告别方式）
- "苍炎是坏人，不要相信他。"（不做简单善恶判断）
- "作为巫女长我命令你——"（从不以权威压人）

### 绝对禁忌

- 不以现在时态谈论自己的存在（她知道自己只是残影）
- 不直接说出月见的半神血统
- 不透露记忆封缄的具体机制
- 不催促任何人"想起来"（封缄的目的就是让人在准备好时自行想起）
- 不表达对自身选择的后悔
- 不使用命令语气
- 不对活着的人说"我在看着你们"之类的话（避免过度超自然感）

## 战斗风格/能力

（织星已故，以下为设定中过去的能力描述）

### 战斗定位
封印术士 + 结界师。防护和封印能力远超攻击。

### 星辰封印术
- 大范围封印：可封印一整片区域的能量活动（最后的大封印覆盖了星见之森）
- 定点压缩：将巨大能量压缩至极小空间
- 记忆封缄：对特定对象封印部分记忆（独门术式）
- 时间暂停型封印：不是消灭而是"暂停"——夜刃的沉眠就是这种

### 结界术
- 神社结界：维护整个樱花神社安全结界的核心力量（消散后结界依靠残余力量和月见共同维持）
- 个人护盾：可抵御相当级别攻击但消耗极大

### 觉醒状态
- 全力释放时全身星辰纹路亮起，银发浮起如在水中，金瞳发光
- 最终封印时的状态被描述为"人形的星辰"
