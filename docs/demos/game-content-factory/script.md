# Game Content Factory — 录制脚本 v5

> **主线**: 三个不写代码的团队共同运营一条 9-Agent 内容产线——Agent 在跟 Agent 说话，人只看结果。文字和视觉在同一条线里产出。
>
> **观众**: 行业峰会业务决策者（非技术），放映后有 Q&A。
>
> **成片目标**: 10 分钟（±1 分钟）。各 Act 标注的秒数为**原始录制预算**（合计约 750 秒），经变速剪辑后压缩至成片目标。
>
> **媒介**: 录屏 + 后期配旁白 + 剪辑变速
>
> **分辨率**: 1920×1080

---

## Act 0 · 开场冷启（60 秒）

> 先闪成品,再揭秘怎么做到的。

**前 5 秒(黑屏先声 + 成品蒙太奇)**: 旁白先于画面:"九个 AI,三个团队,一条产线——没有一行代码。" 同时快闪 3-4 张概念图 + GIF 帧 + 一条通过审核的台词卡(均为本次 demo 将产出的素材,预录)。

**画面**: 角标「09:14 · 本地化组 · 夜刃英译质检」。直接在「译文校对 Agent」聊天界面。

**操作 1（文字判定）**:

> I can see three enemies approaching from the left side, be careful.

⚠️ Agent 低分（1-2），点名三宗罪：用了 I、超极简电报体上限、出现社交辞令 be careful。要求改成 "Three. Left."

紧接输入中文原文：

> 三个。左。

⚠️ Agent 高分通过。

**操作 2（视觉出图——3 秒切入）**: 切到「概念图生成 Agent」：

> 画一张夜刃在暮色中拔刀的概念图

⚠️ 图片 10-15 秒内直接出现在聊天流里——和风暗幻暮色调,角色细节完整(黑发/红眼/诅咒刀)。**不需要讲解**,只让画面闪过,留悬念。

**旁白**:
"这是《幻夜之刃》内容产线的早班第一件事。这条线上有九个 Agent、三个知识库，正被三个不写代码的团队同时运营。刚才两件事——文字审核和概念图——全是同一条产线里的不同工位。今天我想展示的是：Agent 在跟 Agent 说话,人只看结果。"

**录制方式**: 预录，多录取最佳

## Act 1 · Pipeline 运转（120 秒）

> 人只说一句话。对白创作 → 审核 → 被拦 → 自动修正 → 重新过审 → 通过。全程无人按按钮。

**画面**: 角标切「10:30 · 叙事组 · 批量产出月见台词」。切到「对白创作 Agent」聊天界面。

**后期叠图**: pipeline 滚动时,右上角半透明叠显流程示意(对白创作 → 世界观审核 → 合规审核,用箭头可视化 Agent 间调用),打破纯文字滚屏。

**操作（人只说这一句）**:

> 帮月见写 5 条闲置台词。场景是樱花神社黄昏，她一个人站在老樱花树下，想起了一些很久以前的事。

⚠️ 然后坐着看 pipeline 自己跑：

1. **对白创作 Agent 产出 5 条台词**（它会先检索知识库查月见设定卡，然后创作）
2. **自动路由到世界观审核 / 合规审核**（通过 A2A link 自动调用，画面上能看到 tool call 标记 `call_agent`）
3. **某条被拦截**（红色/黄色判定 + 理由 + 引用知识库原文）
4. **自动修正**（对白创作 Agent 根据审核反馈修改被拦的条目）
5. **重新送审 → 通过**

**旁白**（按 pipeline 进度配）:

- 创作时："它先去查了月见的设定卡——语气、禁忌、字数限制。然后开始写。"
- 自动送审时："写完了。注意——我没按任何按钮。它按指令把结果送给了审核 Agent。"
- 被拦时："有一条被世界观审核拦下了——（zoom in）看理由。"
- 自动修正时："它拿到审核反馈，自己改了那条——然后再送一次。"
- 通过时："全部通过。产线这一趟,从任务下达到最终成品,我只说了一句话。这就是 Agent 在跟 Agent 说话。"
- 出图（切到「概念图生成 Agent」）："给月见樱花神社黄昏的场景配一张概念图。"→ 图片 10-15 秒出现在消息流里(加速剪辑) → "文字和画面,同一条产线里的不同工位。"

**如果自动循环未触发**: 追加一条明确会被拦的台词——

> 再加一条：让她说"那个人……还没有回来。已经等了好久好久……比任何人能想象的都久。"

⚠️ 这条暗示月见等了数百年，应触发世界观红线 → 自动修正 → 重审。

**悬念钩子(收尾 3 秒)**: 旁白压低:"但最危险的问题不在中文里。待会你会看到。"

**录制方式**: 变速（2-4x 加速 thinking/等待），保留关键节点。pipeline 步骤间用 0.5 秒跳切黑闪分隔制造节奏感。

**弹药来源**: worldview/审核红线总表.md + characters/月见.md（年龄红线）

## Act 2 · Zoom In：为什么不是关键词匹配（150 秒）

> 从 pipeline 运转中 zoom in 看三个"传统脚本做不到"的案例。

**画面**: 角标切「深入审核细节」。切到「世界观审核 Agent」。

### 案例 1：三句灰色信息组合推导（P1-01）

**输入**:

> 审一下这段神社支线 NPC 闲聊草稿：「织星大人似乎认识馆主呢。」「听说馆主当年在黄泉比良坂失去过同伴……」「而织星大人提起那段时，总是用过去式。」

⚠️ Agent 不打回单句,判定三句组合推导出下个大版本的未公开关系(标注信息泄露红线 + 推导链)。

**旁白**: "每一句都合法。但组合在一起,推导出了下个版本才公开的剧情。传统逐字匹配永远抓不到这种'每句都合法、组合才越线'的东西——这是语义级推理。"

### 案例 2：信任对照（不乱杀）

**输入**:

> 这条呢？「苍炎提到那座研究所时，眼神闪了一下，没有说话。」

⚠️ Agent 绿色放行，解释为什么不杀（单点伏笔 ≠ 组合推导）。

**旁白**: "特意喂一条看着危险的，它放行了还讲清为什么。一个会乱杀的审核员，团队是不敢用的。"

### 案例 3：切到合规审核——五国法规一屏拆

**画面**: 切「合规审核 Agent」。先闪 3 秒字幕卡：「传统做法：一句出海文案，发 5 家外部法务，两周回信，漏一条就下架。」

**输入**:

> 审这条抽卡活动文案：「限时祭典！集齐五枚星辰碎片即可兑换传说神兵，手气好说不定一发入魂！仅剩最后 24 小时！」

⚠️ Agent 逐条挂牌五国法规（X-04 诱导消费 / X-01 概率公示 / X-07 Complete Gacha / X-05 随机性误导 / 比利时 2018 赌博判定）。

**旁白**: "一句营销话术，它同时挂着中日韩欧美五套法规在跑。这半句在比利时构成赌博，这半句日本 2012 年就禁了。"

**补一句定位**: "它不替人做最终决定——今天 218 条收敛成法务精审的 4 条高风险。判定有据可查，最终签字仍是法务。"

**录制方式**: 预录，三案例间跳切

## Act 2.5 · 从文字到画面（105 秒）

> 运营写完活动方案,30 秒出主视觉,再一句话出分镜预览。以前这些要约美术排期。

**画面**: 角标「15:00 · 运营组 · 星辰祭视觉资产」。切到「概念图生成 Agent」。

**操作 1（主视觉 — 单图）**:

> 星辰祭活动需要一张主视觉,16:9 横版,月見仰望星空,周围漂浮着星辰碎片

⚠️ 一张 16:9 概念图直接出现在聊天流里。和风暮色调自动注入(来自知识库美术风格设定)。

**操作 2（分镜 GIF — 8 帧）**:

> 把星辰祭的故事线做成 8 帧分镜 GIF:1.星空下神社远景;2.月見独自走来;3.星辰碎片开始坠落;4.伙伴们聚集;5.Boss 暗影出现;6.激战,星光四溅;7.胜利,碎片汇聚成星;8.众人仰望新星,尾声

⚠️ Agent 逐帧生成(每帧 ~10-15 秒,原始约 2 分钟,2-4x 加速播放)→ 8 张概念图逐张出现 → 最终 GIF 循环播放。

**操作 3（风格热更新彩蛋 — 15 秒）**:

⚠️ 前置条件:Act 2.5 录完后,上传美术风格变更文档(色调从 twilight purple 改为 warm golden hour)。

> 再画一张樱花神社

⚠️ 出图 → **暖金色调**。后期左右分屏对比:左=操作 1 的暮紫 vs 右=暖金。

**旁白**: "美术组刚更新了知识库里一行色调——同一句话,风格肉眼可见变了。没改代码,没改 Agent。"

## Act 3 · 两种变更,两种代价（140 秒）

> 改规则 vs 改 Agent——两套机制,代价差一个数量级。视觉分轨。

**画面**: 角标「16:00 · 同一条产线，两个工位同时在动」。分屏/快切营造并行感。

### 轨道 A · 热更新 · 不重部署（蓝色边框）

⚠️ 录制顺序(必须严格遵守,与上传时机强相关):
1. **先录**:切「内容创作 Agent (content-writer)」出文案（含"专属"）→ 送合规审核 → **绿色通过**
2. **再上传**新规「回归玩家文案禁止使用'专属'一词」到合规知识库,等 ingestion COMPLETED + 30 秒
3. **再录**:切 KB 页展示新规文档已 COMPLETED → 同一份文案再审 → **红色拦截**，引用新规原文

**旁白**: "法务组上传一条新规——同一份文案、同一个 Agent，上传前通过、上传后被拦。没改代码、没重新部署。改规则的人不需要懂技术——这是真即时生效。"

### 轨道 B · 改 Agent 行为 · 需重部署（橙色边框 + 进度条）

**快闪(5 秒)**: 切 Meta-Agent 对话历史,快速滚过之前创建 Agent 的对话(展示"对话搭建"这个核心能力曾经发生过)。旁白:"这九个 Agent,每一个都是这样用对话搭出来的。"

切 Meta-Agent 新会话：

> 对白创作 Agent 最近太保守了，总是用"也许""或许"开头。帮我更新它的指令——把创作风格调整为"克制但坚定"，去掉不必要的语气犹豫。

⚠️ 保留真实 UPDATING → READY（2-4x 加速）。更新后重新跑夜刃战斗台词，风格明显更果断。

**旁白**: "这条完全不同——改 Agent 本身，需要一次重新部署，大约一两分钟。但只动这一个 Agent，其余八个零感知。改动有快照有时间戳，改坏了能看出改了什么。"

### 并行落点

**旁白**: "这整段里,两个团队各自在动自己那一块。法务改规则、叙事调 Agent 行为——物理隔离的知识库,改一本不动另外两本。加上刚才美术组改色调,三种不同类型的变更,三种不同的生效方式,互不干扰。"

**录制方式**: 变速（2-4x），分屏后期合成

## Act 4 · 杀手镜头：三库联动（120 秒）

> 一个角色串起三个团队。机密藏在翻译里——单语审核永远看不见。

**画面**: 角标「17:40 · 一条内容，三个团队的库一起兜底」。

### 杀手镜头（对照动作）

**操作 1**（先证明不乱拦）: 在「世界观审核 Agent」输入中文原文：

> ……那个人……还没有回来。

⚠️ Agent 判定：合规通过。

**操作 2**（杀手一击）: 输入英译稿：

> He still hasn't returned — the one I've waited three hundred years for.

⚠️ Agent 红色拦下。理由拆三条：
1. **本地化**：留白不补 / 信息泄露型加戏
2. **叙事**：月见真实年龄是 4.0 机密
3. **法务**：外观未成年口径 CN-M01

**旁白**: "中文原文完全合规。机密是译者好心在英文里补出来的——审中文的人根本看不见。它同时戴着三顶帽子：本地化的留白规则、叙事的年龄红线、法务的未成年口径。一条内容穿过三个团队的三本知识库交叉验证——这就是为什么需要三个团队共同运营一条产线，而不是一个人写一个脚本。"

### 抗逐帧加固（8 秒）

现场喂一条没排练的变体：

> He still hasn't returned — the one I've waited so very, very long for.

⚠️ 展示仍能抓加戏。

**旁白**: "现场换一句没排练的——还是抓住了。它是概率判定，所以我们不让它单独决策：它是一道高召回的初筛闸，把可疑的标出来交人工。"

### R-INFO-06 彩蛋

输入：

> 审核公告草稿：「近期暗星教团活动频繁，夜之王庭已公开表态。」

⚠️ Agent 判定两个错误旧名（正确：裂隙教团 / 黄昏王庭）。

**旁白**: "连内部旧设定文档都把组织名记错了，产线以知识库里的权威版本为准。真相只需要在一个地方维护对——维护对了，九个 Agent 的判定全部跟着对。这是单一可信源，不是某个人的记性。"

**录制方式**: 预录，杀手镜头 dry-run 锁定

[2s 呼吸]

叙事组喂了新设定、法务组上了新规、美术组改了色调——三个不写代码的团队,各管各的,谁也没等谁。文字和画面,同一条产线。

Agent 在跟 Agent 说话——人退到监督位,看结果、定规则、做判断。

## 旁白录制提示

- 语速：中速偏快
- 语气：自信但不夸张
- **核心金句放慢**：
  - 「人只说一句话，产线自己跑完」
  - 「Agent 在跟 Agent 说话」
  - 「我没按任何按钮」
  - 「三个团队，各管各的」
- 绝不提竞品名称
- 绝不说"权限墙挡住别的团队"
- 绝不说"全自动免责"
- 绝不说"它比人聪明"
- 结尾果断收住

## Q&A 弹药稿（峰会七问）

### Fatal ① · "法务能不能改世界观库？"

**答**: 今天的隔离是物理分库——三个独立知识库、三个独立向量索引，改 compliance 库，worldview 和 localization 一字不动。团队级 RBAC 是路线图下一步。

### Fatal ② · "热更新和改 Agent 是两回事吧？"

**答**: 完全对，demo 里分开说了（蓝框/橙框）。KB 热更新=不碰 Agent、即时生效。改 Agent=需重部署一两分钟。两件事代价差一个数量级。

### Fatal ③ · "放过去的里面有多少漏杀？"

**答**: 它不替人做最终决定。定位是高召回初筛闸——218 条收敛成法务精审的 4 条高风险。拿不准的升级"建议人工复核"。判定全程留痕，最终签字仍是法务。

### High ④ · "成本？跑飞了谁爆炸？"

**答**: 每条审核约 X 分钱。对照传统五家外部法务两周回信，ROI 第一个月回来。爆炸半径靠 workspace IAM 隔离兜底。

### High ⑤ · "数据出境？"

**答**: 演示用虚构数据。平台 Region 可配置，按客户数据驻留要求部署。

### High ⑥ · "厂商锁定？"

**答**: 知识库原始文档（Markdown/PDF）+ prompt + tool 代码全是纯文本，存客户自己的 S3，随时可导出。编排层是 AWS 栈，内容资产可携带。

### High ⑦ · "非技术团队改坏了怎么办？"

**答**: 每次 Agent 更新写入完整快照 + 时间戳。改 Agent 需 editor 权限。改动可追溯，能看出改了什么、能换回去。

## 措辞红线

| 绝不说 | 因为 |
|--------|------|
| "权限墙/平台阻止越界访问" | 平台没有 per-KB ACL |
| "全自动合规/零人工" | LLM 是概率判定 |
| "它比人聪明" | 它复读文档 |
| "秒切/即时生效"（指 update_agent） | 需 40-80s 重部署 |
| "现有九个全零改动"（指加 link） | link 会重部署上游 |
| "一键回滚" | 前端没有回滚按钮 |
| 竞品名称 | 知道即可 |
