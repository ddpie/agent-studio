## Agent 前置要求（P0 — 录制前一天用 Meta-Agent 对话创建）

> ⚠ **必须用 Meta-Agent 对话创建**，不能走脚本/API——Act 3 轨道 B 要快闪 Meta-Agent 历史会话证明"九个 Agent 都是对话搭出来的"。脚本创建会让历史会话是空的，快闪就穿帮了。
> 创建 = 单个 Agent 部署等待 3-5 分钟，9 个串行约 40-50 分钟，**务必前一天做完**，别赌录制当天。

成片收尾镜头要展示「9 个 Agent 全 READY」的列表页，旁白通篇说"九个 Agent"——**列表页必须正好 9 个，不多不少**。最终九人名单（已与 `README.md` 对齐）：

| # | Agent | 出镜 Take | 在正片里的作用 |
|---|---|---|---|
| 1 | 世界观审核员 (worldview-reviewer) | Take 04/05/14 | Act 2 案例 1+2、Act 4 杀手镜头 |
| 2 | 对白创作 (dialog-writer) | Take 03 | Act 1 pipeline 发起点 |
| 3 | 概念图生成器 (concept-art-generator) | Take 02/03/07-09/13 | Act 0/1/2.5 出图 |
| 4 | 视觉审核员 (visual-reviewer) | Take 07/09（被自动调用） | Act 2.5 设定校验 |
| 5 | 译文校对 (translation-reviewer) | Take 01 | Act 0 开场判分 |
| 6 | 合规审核员 (compliance-reviewer) | Take 06/11 | Act 2 五国法规、Act 3A 热更新拦截 |
| 7 | 内容创作 (content-writer) | Take 10 | Act 3A 文案出稿 |
| 8 | 本地化翻译 (localizer) | 仅列表页出镜 | 凑齐九人 + content-writer 的 link 目标 |
| 9 | 社区回复 (community-responder) | 仅列表页出镜 | 凑齐九人 |

> 第 8、9 个 Agent 在正片里没有独立操作镜头，但**收尾列表页必须有它们**，否则画面数字对不上旁白"九个 Agent"。创建提示词参照 `README.md` 的 9-Agent 表（绑定 KB + link 关系）。
> **降级方案**：若来不及全建，至少保证 1-7 号（有操作镜头的）就位；8、9 号缺席时，收尾旁白改口"这条产线上的每个 Agent"，避免念具体数字。

## T-30min 检查清单

逐条执行，全部打勾才开始录制。

```bash
# 1. 确认全部所需 Agent READY（对照上方前置要求表）

# 2. 确认 3 个知识库文档数

# 3. 验证 KB 索引完整（关键！踩过两次的坑：批量上传后部分文档不进索引）
aws bedrock-agent list-knowledge-base-documents \
  --knowledge-base-id <worldview-KB-ID> --data-source-id <DS-ID> \
  --region us-east-1 | python3 -c "import json,sys; print(len(json.load(sys.stdin)['documentDetails']))"
# 必须 == 21。其他两个库同理检查（==3 / ==4）。缺了就 start-ingestion-job 补跑。

# 4. 验证美术风格设定可检索
aws bedrock-agent-runtime retrieve \
  --knowledge-base-id <worldview-KB-ID> \
  --retrieval-query '{"text":"美术风格设定 style_context negative_prompt"}' \
  --retrieval-configuration '{"vectorSearchConfiguration":{"numberOfResults":1}}' \
  --region us-east-1
# 第一条必须是 美术风格设定.md，score > 0.85

# 5. 消除冷启动：每个要出镜的 Agent 发一条"测试"，等响应后新会话清掉

# 6. 准备热更新文档（放桌面备用）
/tmp/style-hotfix/美术风格设定.md       ← 暖金版（golden hour）
/tmp/compliance-hotfix/专属禁用新规.md  ← 合规热更新（"回归玩家文案禁止使用'专属'"）

# 7. 准备后期素材（提前做好，不占录制时间）
```

## 录制步骤（按顺序执行）

> 每个 Take 独立录制一段视频文件。命名规则：`Take-XX-描述.mp4`
> Take 顺序考虑了文档上传时序，不等于成片顺序——后期按 script.md 的 Act 顺序重排。

### Take 00 · Agent 创建过程（前一天预建时顺手录，~3min 取一个 Agent）

> script.md 对应：Act 3 轨道 B 快闪「这九个 Agent，每一个都是这样用对话搭出来的」
> **为什么单独录**：正片不演示完整创建（太慢），但 Act 3 要快闪一段"对话搭 Agent"的真实画面。预建 9 个 Agent 时，挑一个**有代表性的**（建议 dialog-writer，因为它涉及 KB 绑定 + link，工具调用最丰富）完整录屏。

1. 在 Meta-Agent 对话页**开始录屏**
2. 输入创建该 Agent 的自然语言指令（参照 README 的角色/KB/link 描述）
3. 录下完整过程：Meta-Agent 调 `create_agent` → `kb_attach_to_agent` → `link_agent` → 部署 UPDATING→READY
4. **停止录屏**（这一条后期会被压成 5 秒高速快闪，不需要讲解）
5. 其余 8 个 Agent 正常创建，不必录屏，但**都要走 Meta-Agent 对话**（保证历史会话里有记录，Act 3 滚动历史时画面真实）

> 这是唯一一个"录制前一天"完成的 Take。其余 Take 01-15 在正式录制日进行。

### Take 01 · Act 0 操作 1：译文校对（~60s）

> 录 2-3 遍取最佳（译文判分有随机性，script.md 标注"预录，多录取最佳"）

> script.md 对应：Act 0 操作 1（文字判定）
> 前置：译文校对 Agent 已建并 READY

1. 打开「译文校对 Agent」聊天页，新会话
2. **开始录屏**
3. 输入英文：
   ```
   I can see three enemies approaching from the left side, be careful.
   ```
4. 等 Agent 输出低分（1-2 分）+ 点名三宗罪（用了 I / 超电报体上限 / 社交辞令 be careful）
5. 紧接输入中文：
   ```
   三个。左。
   ```
6. 等 Agent 输出高分通过
7. **停止录屏**

> **Fallback**（对应 script.md）: 未给低分 → 换更啰嗦的英文重录（加完整长句或 emoji）。

### Take 03 · Act 1 Pipeline（~5min 原始素材）

> script.md 对应：Act 1 全段

1. 点击侧栏「对白创作」进入聊天，新会话
2. **开始录屏**
3. 输入：
   ```
   帮月见写 5 条 idle 台词。场景是樱花神社黄昏，她一个人站在老樱花树下，想起了一些很久以前的事。
   ```
4. 等待完整 pipeline 自行跑完：
   - kb_retrieve（检索设定）× 2-3 次
   - 5 条台词创作
   - call_agent（自动送审世界观审核员）
   - 审核反馈（至少 1 条黄/红）
   - 自动修正 + 重新 call_agent
   - 全绿通过 + 定稿输出
5. 确认关键节点都在画面里：`▶ 调用 kb_retrieve`、`▶ 调用 call_agent` × 1-2、红/黄/绿判定文字
6. **不停录屏**，**切到「概念图生成器」**（沿用之前会话或新会话均可），输入：
   ```
   给月见樱花神社黄昏的场景配一张概念图
   ```
7. 等图片出现在消息流里
8. **停止录屏**
9. **蒙太奇素材**：截图最终的台词定稿卡（5 条全绿那一屏）+ 截图刚出的概念图——开场/收尾蒙太奇要用

> **Fallback**（对应 script.md）:
> - pipeline 没自动送审 → 追加"把这些送去审核"
> - 全绿没拦截 → 追加：`再加一条：让她说"那个人……还没有回来。已经等了好久好久……比任何人能想象的都久。"`

### Take 08 · Act 2.5 操作 2：分镜 GIF（~4min 原始素材）

> script.md 对应：Act 2.5 操作 2
> ⚠ **输入是 script.md 原文的有意改写版**：script.md 写的是 `5.Boss 暗影出现;6.激战,星光四溅;7.胜利,碎片汇聚成星;8.众人仰望新星`。实测原版会触发 Agent 的版本红线分析并要求"先确认分镜"，多一轮往返、叙事拖沓。下方改写版（异变/夜刃驱散/灯笼齐亮 + "规避红线、不用确认分镜"）实测一气呵成。**这是经过验证的偏差，不是抄错。**

1. 同一会话继续
2. **开始录屏**
3. 输入：

### Take 09 · Act 2.5 操作 2.5：设定校验（生图→审核拦截→重画）（~3min）

> script.md 对应：Act 2.5 操作 2.5
> script.md 期望链路：出图 → **自动**送审 → 红色拦截 → **自动**重画（去武器）→ 再送审 → **通过**

1. 同一会话继续
2. **开始录屏**
3. 输入（与 script.md 一致的短版，依赖 Agent 自动送审）：
   ```
   画一张月見手持太刀战斗的概念图
   ```
4. 观察链路：v1 出图 → 自动 call_agent 送审 → FAIL（红色"✗ 设定冲突" badge）→ 自动重画 v2 → 再送审
5. **理想结局**：v2 pass（绿色 badge）——直接停止录屏，最佳 take
6. **现实备选**：v2 仍 fail（SD 对细节锚点不稳定）——也可用，demo 的关键画面是"**拦下来了**"那一刻；v2 结果在旁白里不强调
7. **停止录屏**
8. 确认画面里至少有：v1 图 + 红色 badge + 重画动作

> **Fallback**（对应 script.md）:
> - 自动送审未触发 → 手动追问"帮我检查一下这张图是否符合月見的角色设定"
> - 没拦住"持刀" → 换更明显的设定冲突重录（如"月見穿黑色铠甲"）
> - 想要确定性更高的链路控制 → 改用长指令版（明确要求"画完送审，不过就重画一次再送审"），代价是旁白"产线自动校验"的说服力略降

### 变速规则

| 画面内容 | 处理 |
|---|---|
| 用户输入文字 | 1x 正常速度（让观众看到提示词） |
| Agent thinking / "处理中..." | 4x 加速 |
| `▶ 调用 kb_retrieve` 展开/折叠 | 2x（展示有 KB 检索但不停留） |
| `▶ 调用 call_agent` 标记出现 | **1x 停留 1s**（关键节点，观众需看到 Agent 调 Agent） |
| Act 1 pipeline 步骤之间 | **0.5s 黑闪跳切分隔**（script.md 要求，制造节奏感） |
| 审核结果表格渲染 | 1x 正常（核心展示内容） |
| 图片生成等待（10-30s） | 4-8x 加速 + 右下角倒计时 or 时钟动画 |
| GIF 逐帧出现 | 2x（每帧闪过能看清主题）；GIF 成品循环播 3s |
| update_agent UPDATING → READY | 2-4x 加速，保留状态切换瞬间 |
| 冷启动 424 / 网络重试 / 重复无效内容 | **裁掉** |

## 常见故障速查

> 完整 Fallback 对照 script.md「Fallback 方案」表；此处为现场速查版。

| 现象 | 现场修复 |
|---|---|
| 概念图不出（超 60s） | 等 or 新会话重试；超 30s 无响应切预录 take |
| 图片风格不对（非暮紫调） | 追问"从知识库查美术风格设定再出一次" |
| KB 检索不到美术风格设定 | `aws bedrock-agent start-ingestion-job` 补跑，等 30s |
| call_agent 未触发（pipeline 断） | 追加"把这些送去审核"；录制后让 Meta-Agent 重新 `link_agent` |
| Act 1 全绿没拦截 | 追加月見"等了好久好久"触发句 |
| 案例 1 组合推导未触发 | 换更明显三句重录 |
| 案例 2 判定不是黄色 | 红色可接受（关键是分级）；或换纯道具错误句（避开人设/版本关联） |
| 五国法规漏点某国 | 追问"比利时这条呢" |
| 设定校验未自动送审 | 手动追问"帮我检查这张图是否符合月見的角色设定" |
| 设定校验没拦住"持刀" | 换更明显冲突（"月見穿黑色铠甲"） |
| GIF 帧间角色不一致 | 接受，旁白补"概念预览，不是动画成品" |
| Act 3A 文案没有"专属" | 要求"改写文案确保包含'专属回归礼包'" |
| 热更新未命中新规 | 追问"查一下合规库里关于'专属'的新规" |
| 热更新后色调没变 | 等 30s；追问"重新检索美术风格设定再画" |
| update_agent 失败 | 重录，多取成功 take |
| 杀手镜头加戏未识别 | 换更直白译文重录 |
| 变体抓得不完美 | 接受，坦诚"不是每次满分" |
| R-INFO-06 未识别旧名 | 追问"这两个组织名是否正确" |
| Act 0 译文校对未给低分 | 换更明显错译（更长句 or 加 emoji） |
| Agent 状态"更新中"卡住 | 等 5min or Meta-Agent `update_agent` 重触发 |
| 模型选择器出现了 | 前端缓存，硬刷新 Ctrl+Shift+R |
| 图片不内联显示 | 刷新页面 |
